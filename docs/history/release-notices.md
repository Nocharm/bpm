## 업데이트 안내 — 버전 관리 강화·신규 화면·에디터 개선 (2026-07-06)

이번 업데이트로 아래 기능이 추가·개선되었습니다. 자세한 사용법은 상단 **사용 매뉴얼**에서 확인하실 수 있습니다.

### 버전 관리가 강화되었습니다

- 게시된 버전에 **버전 번호(v.1, v.2 …)**가 부여됩니다. 새 버전을 게시하면 직전 게시본은 #만료됨 상태로 보존됩니다.
- **점유권(체크아웃)**: 초안은 한 번에 한 사람만 편집합니다. 다른 편집자에게 **점유권 요청**을 보내거나 보유자가 직접 **이전**할 수 있고, 30분 미사용 시 자동 해제됩니다.
- 승인 요청의 **회수**, 게시/만료본에서 새 초안을 만드는 **재게시**를 지원합니다.

### 새 화면 4종이 열렸습니다

| 화면 | 내용 |
| --- | --- |
| **공지사항** | 지금 보고 계신 이 화면 — 중요/일반 필터와 읽음 표시 |
| **알림·승인(Inbox)** | 내가 처리할 승인 요청(버전·점유권·권한)과 알림을 한곳에서 승인/반려 |
| **피드백** | 버그·제안을 관리자에게 바로 전송, 처리 상태와 답변 확인 |
| **사용 매뉴얼** | 한/영 다중 문서 — 제목 드롭다운으로 선택, 목차·본문 검색 지원 |

### 하위프로세스(링크 맵) 사용 방식이 바뀌었습니다

- **지정된 맵만** 라이브러리 피커에 나타납니다. 맵 소유자가 **맵 설정 → 서브프로세스 지정**에서 대표 부서 등 어트리뷰트와 함께 지정하세요.
- 지정 어트리뷰트(부서·담당자·시스템·소요시간)는 그 맵을 링크한 모든 노드에 **라이브로 표시**됩니다.
- 미지정 맵을 가리키는 기존 링크 노드는 경고와 함께 잠기며, 지정하면 다시 풀립니다.

### 에디터가 편해졌습니다

- **자동 정렬 가로/세로**: `Shift+L`(좌→우) / `Shift+K`(상→하) — 시작→대표 끝 주 경로가 한 직선으로 정렬되고 엣지 방향도 함께 맞춰집니다.
- **노드 검색**이 `/` 키 한 번으로 열립니다(초성 검색 지원).
- 단축키 안내는 좌측 사이드바 **단축키 더보기**로 이동했고, 우하단에는 줌 컨트롤이 배치되었습니다.
- **PNG 내보내기**에서 엣지가 누락되던 문제를 수정했습니다 — 모든 연결선이 검은 실선으로, 2배 해상도로 선명하게 출력됩니다.

### 더 빨라졌습니다

- 담당자·협업자 피커와 각종 목록이 **25개씩 끊어 로딩**되어 인원이 많아도 즉시 열립니다.
- 검색 결과 순서가 똑똑해졌습니다 — 단어 시작 일치 우선, 띄어쓰기로 여러 단어 검색(`kim jun`), 부서/그룹 매치는 최상단 고정.
- 맵 상세 정보 로딩 중에는 스피너와 자리표시가 나타나 화면이 덜컹이지 않습니다.

문의나 불편 사항은 상단 **피드백** 버튼으로 보내주세요.

## 업데이트 안내 — 회당 파라미터·가져오기/내보내기·대시보드 (2026-07-13)

이번 업데이트로 아래 기능이 추가·개선되었습니다. 자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 · 사용 안내)에서 확인하실 수 있습니다.

### 노드에 회당 파라미터가 생겼습니다

각 노드에 프로세스를 **한 번 수행할 때**의 비용·소요를 기록할 수 있습니다.

- **6개 값**: 회당 소요시간(h) · 회당 추가비용(원) · 회당 추가비용($) · 회당 투입인원 · 연간 건수 · FTE. 인스펙터의 파라미터 섹션에서 편집합니다.
- **소요시간은 "시.분"**으로 적습니다 — 소수부는 십진수가 아니라 분입니다(`0.30`=30분, `1.30`=1시간 30분). 화면에는 `1h30m`으로 표시됩니다.
- **비용은 한 통화만** — 원(₩)과 달러($)를 동시에 넣을 수 없습니다. 천단위 콤마는 자동으로 붙습니다.
- **하위프로세스 노드**는 연간 건수·FTE만 직접 입력하고, 소요시간·비용·투입인원은 링크한 맵의 지정값을 읽기전용으로 상속합니다.
- 맵을 서브프로세스로 지정할 때 게시본의 파라미터를 **합산 미리보기**(비용은 합, 투입인원은 평균)로 제안합니다.

### CSV·AI로 맵을 빠르게 채웁니다

- **CSV 가져오기**: 상단 바 **가져오기**에서 CSV를 올려 노드를 채웁니다. **제목으로 병합**하므로 기존 노드의 색·댓글·그룹은 유지되고, 빈 칸은 기존 값을 그대로 둡니다. **템플릿 다운로드**로 빈 양식을 받으세요.
- **CSV로 새 맵 만들기**: 홈의 **New map** 옆 드롭다운에서 **Create from CSV**를 고르면 CSV 파일을 드롭해 새 맵을 바로 만듭니다.
- **다른 AI에게 물어보기**: 가져오기 창에서 프롬프트를 복사해 외부 AI에 문서와 함께 붙여넣고, 받은 CSV를 다시 붙여넣을 수 있습니다.
- **AI 도우미 제안**도 같은 방식으로 제목 기준 병합되어 기존 배치·색을 보존합니다.

### 내보내기가 4종으로 늘었습니다

| 형식 | 내용 |
| --- | --- |
| **PNG** | 현재 캔버스 이미지(2배 해상도) |
| **Excel** | 노드 표 — 담당자·부서·회당 파라미터, 통화별 비용 열과 숫자 서식 |
| **CSV** | 가져오기와 같은 14열 — 고쳐서 다시 가져오는 왕복 가능 |
| **Word** | 도형 순서도가 그려진 `.docx` — 노드 링크는 하이퍼링크로 |

### 운영 대시보드가 넓어졌습니다

- **설정 → 분석**의 대시보드에 운영 지표(맵·버전 상태·부서별 도입률·로그인/활동·누적 증가·최근 버전 이벤트·AI 사용량)와 기간 필터가 추가되었습니다.
- 대시보드 **열람 권한을 위임**할 수 있습니다 — 관리자가 사람·부서·유저그룹에 접근 권한을 부여하면 관리자가 아니어도 대시보드를 볼 수 있습니다.

### 그 밖에

- **자동 로그인**: 한 번 로그인하면 다음 방문부터 자동으로 로그인되고, 처음 열려던 화면으로 이어집니다.
- **노드 링크(URL)**: 노드에 외부 문서·시스템 링크를 달면 배지가 뜨고, 클릭해 미리보기·새 탭 열기를 할 수 있습니다. 표시 이름(라벨)도 지정할 수 있습니다.

문의나 불편 사항은 상단 **피드백** 버튼으로 보내주세요.

## 업데이트 안내 — 홈 개편·승인 워크플로·서브프로세스 연결 (7월 2차)

<!-- 게시 시: 제목 끝의 (7월 2차)를 실제 배포일로 바꾸거나 유지. 중요도 '중요' + 게시 시 전체 알림 권장. -->

이번 업데이트로 아래 기능이 추가·개선되었습니다. 자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 · 사용 안내)에서 확인하실 수 있습니다.

### 홈 화면이 새로워졌습니다

- **좌측 조직도**로 부서별 맵을 탐색합니다 — **나의 부서**는 즐겨찾기로 맨 위에 고정됩니다.
- 홈 우측에 **현황 대시보드**가 생겼습니다 — 맵 상태 도넛 차트, 최근 열어본 맵, 내가 처리할 승인.
- 맵 카드·상세에 **오우닝 부서**와 **SP 배지**(서브프로세스 지정 맵)가 표시됩니다.
- 새 맵에는 **시작·종료 노드가 자동으로** 만들어져 바로 그리기 시작할 수 있습니다.

### 승인 워크플로가 편해졌습니다

- **셀프 게시** — 결재자가 본인 1명이면 승인 요청 시 "바로 게시할까요?" 팝오버로 제출→승인→게시를 **원클릭**으로 끝냅니다.
- **맵 이름 변경 요청** — 편집자가 이름을 바꾸면 오너에게 승인 요청이 가고, 오너는 Inbox에서 승인/반려합니다(오너는 지금처럼 즉시 변경).
- 새 버전을 만들 때 이름을 직접 입력하고, **버전 번호는 게시 시 자동 부여**됩니다.

### 서브프로세스 연결이 유연해졌습니다

- **미등록 맵도 먼저 링크(플레이스홀더)** — 프로세스 라이브러리의 "Show unregistered maps"를 켜면 아직 서브프로세스로 지정되지 않은 맵도 드래그해 링크할 수 있습니다. 링크하면서 대상 맵 오너에게 **등록 요청**을 보내면, 오너가 Inbox에서 지정 폼을 저장하는 것으로 수락됩니다.
- **새 맵을 그 자리에서** — 라이브러리에 검색어를 입력하면 나타나는 **"검색어"로 맵 만들기** 버튼으로 이름이 채워진 생성 창이 뜨고, 만들자마자 현재 맵에 자동으로 링크됩니다.
- 상단 맵 드롭다운에서 서브프로세스 지정 맵은 보라 아이콘, **사용 중인 맵은 보라 배경**으로 표시되고, 사용 중인 맵을 클릭하면 캔버스의 해당 노드로 이동합니다.
- SP 목록은 우클릭 또는 **`S` 단축키**로 열고(한글 초성 검색), 같은 맵은 두 번 링크되지 않습니다. 새 링크는 기본으로 **최신 게시본을 자동 추종**합니다.
- 지정 폼에 **설명** 항목이 생겼고, 하위프로세스 노드를 선택하면 인스펙터 **Subprocess 탭**에서 지정 정보와 "이 맵을 쓰는 곳" 목록을 볼 수 있습니다.

### 편집이 빨라졌습니다

- **노드 복사/붙여넣기** — `Ctrl+C` / `Ctrl+V`. 다른 탭·다른 맵에도 붙여넣을 수 있습니다. `Ctrl`+드래그로 복제.
- **`Shift`+드래그**로 노드를 한 축(수평/수직)으로만 이동해 줄 맞추기가 쉽습니다.
- **그룹 일괄 편집**에서 회당 파라미터 6개 값도 한 번에 채웁니다.

### 그 밖에

- **Excel 내보내기 형식 2종** — 구조 정리형(분기 주석 포함)과 **WBS형**(하위프로세스를 레벨로 펼침) 중 선택합니다.
- **알림 정리** — 카테고리 필터, 선택 삭제·읽은 알림 삭제·날짜 지정 삭제를 지원하고, 알림은 1인당 최근 100건까지 보관됩니다.
- 사용 매뉴얼에 **At a glance** 드롭다운이 생겨 문서를 빠르게 오갈 수 있습니다.

문의나 불편 사항은 상단 **피드백** 버튼으로 보내주세요.

## 업데이트 안내 — 승인 코멘트·협업자 관리·인물/조직 정보 (8월)

<!-- 게시 시: 제목 끝의 (8월)을 실제 배포일로 바꾸거나 유지. 중요도 '중요' + 게시 시 전체 알림 권장. -->

이번 업데이트로 아래 기능이 추가·개선되었습니다. 자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 · 사용 안내)에서 확인하실 수 있습니다.

### 승인 워크플로에 코멘트가 생겼습니다

- **단계별 코멘트** — 제출·승인·게시·철회 때 선택 코멘트를 남길 수 있습니다. 반려 사유는 상대방 알림에도 함께 담겨 전달됩니다.
- **코멘트 이력** — 버전 카드·버전 타임라인의 말풍선 버튼으로 그 버전에 오간 코멘트를 한 번에 봅니다.
- 승인/반려 창에는 **요청자의 제출 코멘트**가, 다시 제출할 때는 **직전 반려 사유**가 미리 보여 맥락을 놓치지 않습니다.
- 에디터의 **승인 워크플로 패널이 새로워졌습니다** — 승인 상태 태그에 마우스를 올리면 처리 시각과 코멘트가 툴팁으로 뜨고, 승인자 이름에서는 인물 카드가 열립니다.

### 협업자 관리가 안전하고 편해졌습니다

- **모아서 저장** — 협업자 추가/제거/역할 변경을 쌓아 두고 **Save 한 번**에 적용합니다(Cancel로 전부 취소). 각 변경에는 **즉시 적용되는지, 오너 승인이 필요한지** 아이콘(번개/모래시계)으로 미리 표시됩니다.
- **승인 대기 표시와 회수** — 승인이 필요한 변경은 해당 협업자 행에 대기 태그로 표시되고, 본인이 요청한 건은 그 자리에서 바로 **회수**할 수 있습니다.
- **되돌리기** — 방금 저장한 변경 묶음을 **Undo 한 번**으로 되돌립니다.
- 홈 **맵 카드에서도** 협업자를 바로 추가/제거할 수 있습니다(편집자 이상).
- 오우닝 부서 선택 창이 **조직도 트리**로 바뀌어 내 소속 부서가 맨 위에 고정됩니다.

### 게시와 공개 범위를 한 번에 처리합니다

### 노드에 입출력과 조건을 직접 기록합니다

- 항목마다 **자료 형식**을 붙일 수 있습니다 — 행의 파일 아이콘을 누르면 자동완성 목록이 열리고, `.xlsx` / `Excel` / `엑셀` 어느 쪽으로 검색해도 같은 항목을 찾아 줍니다.

- **실작업시간(Touch time)**이 추가되었습니다 — 소요시간과 같은 `시.분` 규칙(`1.30` = 1시간 30분)입니다. CSV 가져오기/내보내기와 Excel에도 함께 들어갑니다.

- 분류를 고르면 **노드 색이 분류 색으로 자동 지정**됩니다(Direct=빨강, Indirect=앰버, Non-GMP=초록). 안내 창에서 **이전 분류로 되돌리기 / 색만 되돌리기**를 고를 수 있습니다.

- **연결선 라벨 변경**도 노랑으로 감지되고, 연결선은 맵에 저장된 **선 모양 그대로** 그려집니다.

- 업무 체계 보기에서 분류 행을 클릭하면 **직계 하위 분류와 소속 맵 목록 패널**이 열리고, 맵 카드는 제목 중심으로 정돈되었습니다. 부서·업무 체계 트리에서 행에 마우스를 올리면 **상위 경로가 가이드 라인과 함께 강조**됩니다.

### 업무 체계 연계 캔버스(L5)와 확정 거버넌스

- 홈 Framework 트리의 L5 행에서 **연계 캔버스**를 열면 그 분류에 속한 L6 맵 전체가 하위프로세스 노드로 배치된 캔버스에서 L6 사이의 흐름을 그립니다. 다른 분류의 L6는 출처 색 탭과 배지로 구분되고, 좌상단 **L5 탐색기**로 다른 분류로 이동합니다. 캔버스는 "새벽 조감도" 다크 배경이며 우상단 토글로 라이트로 바꿀 수 있습니다.
- 캔버스는 게시 대신 **확정(Confirm)**으로 스냅샷을 남깁니다 — 확정 게이트 6종(미배치 L6·플레이스홀더·끊긴 링크·미게시 L6·출구 없는 순환·디시전 없는 분기)을 통과해야 버튼이 켜지고, 확정권이 없는 상위 권한자는 **확정 요청**을 보냅니다. 확정본에는 `CONFIRMED vX.Y` 스탬프가 찍히고, 열람자는 항상 최신 확정본을 봅니다(초안은 권한자만).
- 아직 등록되지 않은 L6 자리는 **플레이스홀더**로 두었다가 **연결(Connect)** 창에서 실제 맵으로 교체합니다. 슬롯이 이양·대체·삭제되면 캔버스 노드가 자동으로 바뀌고, 사라진 L6는 배너와 **Replace** 버튼으로 후계 맵을 고를 수 있으며, 노드 호버 시 **슬롯 이력**이 보입니다.
- 관리자는 카테고리 권한자(Linkage admins)를 어느 레벨에나 지정할 수 있고, 설정 → Framework의 **현황판(Status)**에서 범위 안 모든 L5의 확정 상태와 실패 게이트를 한눈에 봅니다.

### 체계 슬롯 변경은 승인으로 처리됩니다

- 맵 카드 체계 필의 **연결·이동·해제·이양**과 슬롯 맵의 삭제·복사 후 원본 대체가 하나의 승인 종류로 통일되었습니다. 해당 L5의 직속 권한자와 시스템 관리자는 확인 창에서 바로 적용하고, 그 외 사용자의 변경은 승인 요청이 되어 받은함·맵 승인 탭·승인 큐에 나타납니다(이동은 양쪽 L5 각 1명 승인). 대기 중에는 배너(n/m)가 보이고 요청자가 철회할 수 있습니다.
- 맵 슬롯은 **L5에만** 둘 수 있습니다. 상위 분류(L1~L4)로의 배정·이양은 안내와 함께 차단됩니다.

### 노드에 담당자와 별개로 "역할"을 적습니다

- 노드·하위프로세스 지정에 **역할(Role)** 칸이 생겼습니다 — "구매 담당자", "QA 검토자"처럼 실명이 아닌 역할명을 하나 적습니다. 인스펙터의 Role 행, 노드 편집 창과 지정 창의 담당자 옆 타일, 그룹 일괄 편집에서 입력하며 관리자가 등록한 **역할 목록**이 자동완성으로 뜹니다(목록에 없는 값도 그대로 저장).
- 캔버스 노드는 평소에 **역할**을, 노드에 마우스를 올리거나 선택하면 잠시 뒤 **담당자 이름 칩**을 보여줍니다. 라이브러리·미리보기·홈 맵 상세·비교 화면·Excel에도 역할이 함께 표시됩니다.
- **시스템** 칸은 관리자가 등록한 **시스템 목록**과 대조합니다 — 별칭(예: `sap`)을 적어도 정식 표기(`SAP ERP`)로 저장되고, 목록에 없는 값은 **Other**로 분류하면서 적은 원문을 **원문 메모**로 남깁니다(기존 메모가 있으면 교체/추가/취소 선택). Other 노드는 캔버스에 원문 메모가 한 줄로 표시됩니다.
- 목록은 시스템 관리자가 **설정 → 조직 → Catalogs** 탭에서 관리합니다(역할·시스템 탭, 별칭 편집, `value,aliases` CSV 임포트, 사용 중인 값 승격).

### AI는 이제 담당자 대신 역할을 채웁니다

- AI 도우미의 순서도 생성/부분 편집과 AI 컨설턴트 인터뷰는 **담당자 실명을 지정하지 않습니다** — 사람에 관한 값은 **역할**로만 채우고, 담당자는 에디터의 담당자 피커에서 직접 지정합니다. 인터뷰는 역할·시스템 단계에서 활동별 역할을 목록 후보와 함께 묻습니다.
- AI가 적는 시스템도 시스템 목록의 정식 표기로 맞춰지고, 목록에 없으면 Other + 원문 메모로 들어갑니다.

### CSV에 Role 열이 생겼습니다

- 가져오기/내보내기 CSV에 **Role** 열(Assignee 다음)이 추가되어 역할이 왕복합니다. 템플릿과 "다른 AI에게 물어보기" 프롬프트도 함께 갱신되었습니다.
- CSV의 System 값도 목록과 대조합니다 — 별칭은 정식 표기로, 미일치 값은 Other + 원문 메모로 저장되며, 기존 메모와 다르면 기존 메모를 지키고 경고를 표시합니다. Other 노드를 내보내면 System 셀에 원문 메모가 실려 다시 가져와도 같은 상태로 돌아옵니다.

### 노드 편집 창과 인스펙터가 정돈되었습니다

- 노드 더블클릭(또는 정보 수정)으로 여는 **노드 편집 창**이 타일 구성으로 바뀌었습니다 — 유형·색·속성·수행 지표 7종·입출력/조건을 타일로 보고, 타일을 클릭하면 그 자리에 입력 팝오버가 열립니다. 저장 버튼 없이 **노드와 인스펙터에 즉시 반영**되고(되돌리기 `Ctrl+Z`), 창 좌우의 **이전/이후 노드 카드**를 클릭해 바로 넘어갑니다.
- **입력물·산출물의 자료 형식**은 항목마다 붙입니다(노드 단위 자료 형식은 폐지). 인스펙터의 속성 행은 높이와 아이콘이 통일되었고, 부서는 말단 부서 필, 담당자는 인물 필(호버/클릭 인물 카드)로 보입니다.
- 조직도에 없는 부서·담당자가 남은 노드는 속성 줄 아이콘이 **경고색**으로 바뀌고 우하단 배지에 건수와 사유(미등재·열람 권한 없음·부서 변경)가 표시됩니다.
- 하위프로세스 **미리보기 피크**가 확장되었습니다 — 라이브러리 행 클릭/호버로 게시본을 미리 보고(휠 줌·드래그 팬), 노드 목업을 **드래그해 캔버스에 추가**하며, "해당 맵으로 이동"으로 바로 갑니다. 라이브러리에는 **Filter**(미등록 맵 스위치·부서 트리·권한 필)가 생겼고, 하위프로세스 노드는 우하단 그립으로 **폭을 조절**할 수 있습니다.
- 펼친 하위프로세스 안에서 `Tab`/`Shift+Tab` 순회가 경계를 넘나들며, 중첩 펼침 영역의 우클릭 메뉴는 가장 안쪽 맵을 기준으로 열립니다. 인스펙터 **Subprocess 탭**에는 지정 파라미터 읽기 타일과 게시본 이동 안내가 추가되었습니다.

### 데이터 품질 — 낡은 참조를 찾아 정리합니다

- 조직개편·퇴직으로 부서·담당자·사용자 참조가 낡은 맵에는 카드에 **Stale refs 배지**가 붙고, 홈 필터 **Issues**(오우닝 누락·낡은 참조)로 모아 볼 수 있습니다. 오너에게는 수정 요청 알림이 묶음으로 갑니다.
- 관리자는 **설정 → 조직 → Orphaned refs**에서 노드·지정·권한·그룹·카테고리 권한자 등 12곳을 한 번에 스캔하고, 값별로 묶어 체크한 항목을 **일괄 교체/제거**합니다(기존 "소멸 부서 재지정"을 대체).

### 관리자용 — 인터뷰 임포트와 운영

- 컨설턴트 인터뷰 JSON은 **0.4(흐름 그래프)와 0.5(외부 L6 참조 `externalTasks`)**를 받습니다. 흐름 엣지가 맵과 L5 연계 캔버스에 착지하고(분기·루프·자동 정렬·IO 자동 연결·편집용 초안 생성), 다른 분류의 L6는 자리표시자로 두었다가 나중 전달에서 자동 연결됩니다. `ownerRole`은 지정 역할로, 시스템 값은 카탈로그로 정규화되어 들어옵니다.
- **Dry-run 리포트**가 2열로 재구성되었습니다 — 좌측 요약·확인 필요·외부 L6·카테고리 관리자·거버넌스 변경, 우측 파일 카드와 맵 목록(행 미리보기·L5 캔버스 미리보기·임포트 노트 내용 diff). 재임포트 시 오너·부서·승인자·노트는 **체크한 항목만 교체**됩니다.
- 설정 → 데이터베이스 → **Batch jobs**에서 DB 백업·HR 동기화의 최근 결과를 보고 **지금 백업**·백업 파일 다운로드를 할 수 있습니다. 운영 서버는 매일 04:00 자동 백업(14일 보존)됩니다.

### 그 밖에

- 알림 26종 전부가 맵 이름·버전·행위자·사유를 갖춘 **리치 카드**로 렌더되고, 받은함의 행위자는 인물 카드로 열립니다.
- 협업자·담당자 피커의 기본 순서가 **내 조직에서 가까운 사람 순**으로 바뀌었습니다.
- 버전 비교 화면은 기준/대상 캡션과 상태 필 드롭다운으로 버전을 고르고, 필드 차이를 생성(초록)·삭제(빨강)·변경(노랑)으로 구분합니다.
- 반려된 버전의 편집권은 제출자에게 돌아갑니다. 복사 후 원본을 대체(은퇴)할 때 협업자·승인자가 미리 채워집니다.
- 큰 맵(300노드 이상)의 드래그가 부드러워졌습니다.
- 매뉴얼 6종이 최신화되었고, 실화면 슬라이드 매뉴얼(사용자/관리자, HTML·PDF)이 추가되었습니다.

자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 9장 "PNG 옵션 창", 4장 "A4 가이드")에서 확인하실 수 있습니다.

### PNG 내보내기에 옵션 창이 생겼습니다

PNG 버튼(인스펙터·우클릭 메뉴·`Ctrl+Shift+E`)을 누르면 이제 **옵션 창**이 먼저 열립니다.
위쪽 미리보기 샘플이 고른 옵션을 바로 보여 주고, 마지막 선택은 브라우저에 기억됩니다.

- **화면 그대로**: 지금까지와 같은 출력입니다(캔버스 톤·점 격자·노드 색, 하단 맵 정보 카드).
- **Word 문서용**: 사내 문서에 붙이기 좋은 흰 바탕 순서도입니다.
  - 글꼴은 **Arial + 맑은 고딕**이고, 노드 색은 고른 스타일(**모노 / 그레이 / 그레이 + 네이비**)로 통일됩니다.
  - 모서리는 각지게, 분기 라벨은 문서 톤 하나로 바뀌고, 코멘트·경고 배지 같은 편집용 표시는 빠집니다.
  - **병렬 표시**(병렬 출구 뒤 이중 세로선과 범례), **맵 정보 블록**(그림 위 제목과 메타 한 줄), **교차 표시**(연결선이 엇갈리는 곳을 점프 또는 터널로)를 칩으로 켜고 끕니다.
- **표시 정보**(두 형식 공통): 담당자·부서·시스템·GMP·수행 지표·입력물·산출물·조건 중 노드에 담을 정보를 고릅니다. 고른 값은 내보내는 순간에만 적용되고, 캔버스의 표시 설정은 그대로 남습니다. **입출력 펼침**을 켜면 입출력 목록을 전부 담고, 판단 노드의 입출력도 펼친 목록으로 인쇄합니다.

### Word에 넣을 크기를 미리 확인합니다

Word 문서용을 고르면 창 오른쪽에 **인쇄 크기** 패널이 펼쳐집니다.

- **A4 세로 / 가로**와 **그림 너비**(본문 폭의 30~100%)를 고르면, 페이지 미리보기에 본문 대비 그림 크기가 실제 비율로 보입니다.
- **크기(cm) · 해상도(dpi) · 노드 글자(pt)**를 함께 보여 주고, 글자가 7pt 미만으로 작아지면 "읽기 어려움"으로 알려 줍니다.
- 해상도는 300dpi에 가깝도록 자동으로 올라가고, Word에 그림을 넣으면 고른 너비로 들어가도록 만들었습니다.

### 그리는 단계에서 A4 폭을 맞추는 A4 가이드

캔버스 우하단 **눈 아이콘** 카드 맨 위에서 **A4 가이드**를 켜면 캔버스에 경계선이 그려집니다.

- **9pt 실선** 안에 맵이 들어오면, A4 본문에 넣었을 때 노드 제목이 9pt 이상으로 인쇄됩니다.
- **7pt 최소** 점선보다 넓으면 인쇄물에서 읽기 어려우니, 자동 정렬 세로(`Shift+K`) 등으로 폭을 줄여 보세요.
- A4 세로/가로를 고를 수 있고, 화면에만 보이는 안내선이라 저장·출력에는 들어가지 않습니다.

### 노드의 조건과 입출력이 한눈에 보입니다

- **시작/종료 조건**은 모든 노드 밖에 한 줄 캡션으로 붙습니다(시작은 위, 종료는 아래, 마우스를 올리면 전문).
- **판단 노드**의 입출력은 마름모 아래 **아이콘+개수 알약**으로 요약되고, 마우스를 올리거나 선택하면 같은 자리에서 목록으로 펼쳐집니다. 체크한 항목이 있으면 `체크/전체`로 표시됩니다.
- 다른 노드에서 불러온 입출력이 흐름을 따라 넘어가는 연결선에는 **넘어가는 항목 수**가 보라색 숫자 점으로 붙습니다. 점에 마우스를 올리면 항목과 출처 노드(**From**)를 카드로 보여 줍니다.

### 비교 화면의 색이 익숙한 관례로 바뀌었습니다

- **추가 초록 · 변경 앰버 · 삭제 빨강**으로 표시하고, 바뀌지 않은 노드와 흐름 점은 회색으로 물러나 바뀐 곳이 먼저 보입니다.
- 범례 옆 **색 견본**을 누르면 연두(추가)·청록(변경) 팔레트로 바꿀 수 있습니다.
- 조건은 노드 위·아래 캡션으로만 보이고(바뀐 조건은 마우스를 올리면 이전 → 이후), 입출력은 늘고 준 개수만 한 줄로 요약됩니다.

### 내 화면 설정: 유리 효과와 강조 색

상단 바의 내 이름(사용자 메뉴) → **화면 설정**에서 바꿀 수 있습니다.

- **유리 효과**: 떠 있는 메뉴·카드·대화창의 반투명 표면을 끄고 불투명한 흰 표면으로 쓸 수 있습니다.
- **강조 색**: 버튼과 선택 표시의 포인트 색을 **바이올렛 / 블루 / 오션 / 플럼** 중에서 고릅니다.
- 이 브라우저에만 저장되며, 맵 데이터나 다른 사람의 화면에는 영향이 없습니다.

### 그 밖의 개선

- **결재 대기 카드**가 인스펙터 폭과 관계없이 세로로 정리되어, 좁은 화면에서도 요청 내용이 잘리지 않습니다. 대상과 요청자는 아이디 대신 이름·부서로 보이고, 요청 시각이 함께 표시됩니다.
- **공지사항과 사용 매뉴얼**의 본문이 더 읽기 쉬워졌습니다. 한 줄 바꿈은 그대로 줄이 바뀌어 보이고, 문단과 제목 사이 간격이 넓어졌습니다.

이번 업데이트로 아래 기능이 추가·개선되었습니다.
자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 9장 "내보내기", 7장 "저장과 검증", 11장 "업무 체계 연계 캔버스")에서 확인하실 수 있습니다.

### 긴 맵도 Word에서 읽히게: 나눠 싣기

PNG 옵션 창에서 **Word 문서용**을 고르면 오른쪽 인쇄 크기 패널에 **나눠 싣기**가 생겼습니다.

- **읽을 수 있게 나눔**을 고르면 노드 글자가 7pt 이상으로 찍히도록 맵을 **노드 사이 빈 칸에서 세로로 잘라** 조각마다 PNG를 만들고, 전부를 **ZIP 파일 하나**로 내려받습니다.
- 모든 조각이 같은 배율이라 Word에 차례로 넣으면 글자 크기가 일정합니다. 잘린 연결선은 양쪽 조각 끝에 **같은 문자(A·B…)**가 붙고, 조각마다 `1/5` 같은 번호가 들어갑니다.
- **맵 정보 블록과 범례는 인쇄 크기가 고정**됩니다(제목 11pt, 메타·범례 7.5pt). 맵이 길어 그림이 줄어도 같이 작아지지 않습니다.
- **연결선 펼침** 칩으로 같은 핸들의 연결선을 화면처럼 펼칠지(기본) 한 점에서 겹쳐 낼지 고릅니다.
- 표시 정보나 문서 글꼴 때문에 노드 크기가 달라져도 **캔버스에서 맞춘 가운데·오른쪽·아래 정렬이 출력에 그대로** 남습니다.
- 노드의 입력물 상자는 왼쪽 위, 산출물 상자는 오른쪽 아래 모서리가 **사선**으로 잘려 화면과 PNG 모두 모양만으로 구분됩니다.

### 비교 화면 PNG에도 옵션 창이 생겼습니다

비교 화면 **내보내기**를 누르면 **비교 PNG 옵션 창**이 먼저 열립니다.

- **화면 그대로** 또는 **문서용**(흰 바탕, 바뀌지 않은 항목은 회색, 추가·변경·삭제 색은 지금 고른 색 구성 그대로)을 고릅니다.
- **정보 블록**(맵 이름·기준 → 대상 버전·건수), **범례**, 노드에 담을 **표시 정보**를 칩으로 켜고 끄며, 문서용은 인쇄 크기·연결선 펼침·나눠 싣기도 고를 수 있습니다.
- 연결선의 추가·삭제·변경 색과 점선이 이미지에 그대로 담깁니다(전에는 모두 검은 실선이었습니다).

### Excel은 바로 인쇄할 수 있는 문서로 나옵니다

- 맨 위에 맵 이름·주관 부서·오너·버전·게시일·내보낸 시각 정보 줄이 오고, **A4 가로 한 장 폭**에 맞춰 인쇄되며 머리글 행이 쪽마다 반복됩니다. 머리글 행과 이름 열은 고정되고 필터가 걸려 있습니다.
- **소요시간·실작업시간은 Excel 시간 값**(`1.30` → `1:30`)으로 담겨, SUM으로 더해도 시:분이 맞게 합산됩니다.
- 내보내기 창의 미리보기가 실제 파일 모양(정보 줄과 고른 열)을 보여 줍니다.

### CSV 내보내기와 다시 가져오기가 매끄러워졌습니다

- 내보내기 창 안에서 **미리보기와 경고**를 먼저 보고 내려받습니다. 같은 제목의 단계나 이름 없는 단계가 있으면 다시 가져오기 전에 고치도록 알려 줍니다.
- `=`·`+`·`-`·`@`로 시작하는 칸은 Excel이 수식으로 실행하지 않도록 앞에 `'`를 붙여 내보내고, 다시 가져오면 원래 글자로 돌아옵니다.
- 같은 맵으로 다시 가져올 때 제목의 앞뒤 공백은 무시하고 맞추며, 시작 연결은 그대로 둡니다.
- 따옴표가 닫히지 않은 파일은 문제가 시작된 줄을 알려 주고, UTF-8이 아니어서 EUC-KR로 읽은 파일은 글자가 깨지지 않았는지 확인하라고 경고합니다.

### 저장하지 않은 편집을 두고 나가면 확인합니다

- 저장되지 않은 편집이 있을 때 앱 안 다른 화면으로 이동하면 확인창이 뜹니다. **저장하고 이동 / 저장하지 않고 이동 / 머무르기** 중에서 고르세요.
- 브라우저 뒤로 가기는 물어볼 수 없어 바로 저장하고, 탭을 닫거나 새로고침하면 브라우저 경고가 뜹니다.

### 승인 요청 전에 확인하는 것이 늘었습니다

- 종료가 **둘 이상**인 맵은 그중 하나의 **Primary end**를 직접 켜야 승인 요청할 수 있습니다(종료가 하나면 자동). 이 맵을 하위프로세스로 쓰는 부모 맵의 기본 출구가 다른 끝(예: 반려)으로 바뀌지 않게 하기 위해서입니다.
- "갈래는 판단 노드나 병렬 출구로" 규칙을 맵 설정 화면의 승인 요청·셀프 게시도 에디터와 똑같이 확인합니다.
- 제출자가 퇴사했거나 그 맵의 편집 권한을 잃었다면 **시스템 관리자가 대신 게시·회수**할 수 있습니다.
- 진행 중인 버전(Draft·검토 대기·승인됨·거절됨)이 있으면 재게시할 수 없습니다. 버전 이름은 Draft·거절됨 버전에서 check out한 사람·오너·시스템 관리자만 바꿀 수 있고, 만료된 버전은 삭제할 수 없습니다.

### 업무 체계 연계 캔버스(L5)

- **확정 요청**이 대기 중이면 직속 L5 권한자와 시스템 관리자만 check out할 수 있고, 요청한 사람의 화면은 **Confirm requested** 안내와 함께 읽기 전용이 됩니다. 철회하면 곧바로 다시 편집할 수 있습니다.
- 확정이나 확정 요청을 누르면 아직 저장되지 않은 편집을 먼저 저장한 뒤 진행합니다.
- 다른 L5의 L6를 참조하는 노드는 그 맵의 하위프로세스 등록이 해제되면 **지정 해제됨** 배너가 뜨고 끊긴 링크로 셉니다.
- 분류 권한자에서 빠지면 알림으로 알려 드립니다.

### 그 밖의 개선

- 캔버스가 다시 부드러워졌습니다. 가만히 있거나 휠로 이동할 때 끊김이 사라졌고, 맵 전체를 축소한 상태에서 노드를 끄는 것도 빨라졌습니다.
- 내려받는 파일 이름의 시각이 한국 시간으로 붙습니다(오전에 받은 파일이 전날 날짜로 찍히던 문제).
- 볼 권한이 없는 맵은 하위프로세스로 새로 연결할 수 없고, 승인자 목록은 오너와 시스템 관리자만 바꿀 수 있습니다.
- 노드 제목·연결선 라벨·사용자 그룹 이름은 최대 200자입니다.
- 승인 요청 뒤 상단 바에 "편집 중 - 읽기 전용"이 남던 문제와, 좁은 화면에서 저장 버튼이 밀려나던 문제를 고쳤습니다.
- 공지 게시 기간을 수정할 때마다 시작일이 하루씩 당겨지던 문제를 고쳤습니다.
- 사용 매뉴얼 PDF 창은 지금 화면 언어의 PDF를 먼저 보여 줍니다.

### 관리자 화면(시스템 관리자)

- **설정 → 배치 작업**의 HR 카드 아래에 **동기화 회차 이력**이 쌓입니다. 회차마다 신규·퇴직·재입사·삭제·중복 ID 건수가 보이고, 펼치면 바뀐 사람의 명단이 나옵니다. 퇴직 처리가 한꺼번에 많으면 동기화를 멈추지 않고 **Mass departure** 배지로 표시합니다.
- **지금 백업**이 운영 서버에서도 정상 동작합니다.
- 인터뷰 JSON 재전달·AI 컨설턴트 등록에서 사람이 다듬은 값이 같은 활동에 이어집니다(활동을 끼우거나 빼도 값이 옆 활동으로 밀리지 않음). 유지한 L6는 등록이 다시 쓰지 않고, 기존 분류를 다른 상위로 옮기려는 파일은 거부됩니다.
