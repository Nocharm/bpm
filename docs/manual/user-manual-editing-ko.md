# Business Process Map — 맵 편집

> Business Process Map(BPM)에서 **프로세스맵을 그리고 편집하는 방법**을 다룹니다 — 노드·연결·그룹·회당 수행 지표·하위프로세스·저장·가져오기/내보내기·AI 도우미까지. 로그인·맵 목록·버전 승인·설정 등 편집 외의 사용법은 **사용 안내** 매뉴얼을 함께 보세요.

---

## 1. 에디터 둘러보기

맵을 열면 에디터로 들어갑니다. 상단 바에 버전 선택, **새 버전**, **비교**, **실행취소** / **다시실행**, **저장**, 프로세스 라이브러리, **가져오기(CSV)**, **AI 도우미**가 있습니다. 우측 인스펙터에서 선택한 노드의 속성을 편집하고, 좌측 사이드바에 아웃라인 트리와 단축키 카드가 있습니다. 인스펙터 탭 바 맨 오른쪽 아이콘은 현재 탭의 **모든 섹션을 한 번에 접거나 펼칩니다**(하나라도 펼쳐져 있으면 모두 접기, 모두 접혀 있으면 모두 펼치기). 업무 체계(Framework)에 등록된 맵이면 캔버스 **좌상단**에 **Framework 칩**이 분류 경로를 보여줍니다(맵 제목과 저장 체크리스트는 우상단) — 칩을 펼쳐 카테고리 행을 누르면 그 분류에 속한 다른 맵 목록이 열리고, 클릭해 바로 이동할 수 있습니다(저장 안 된 변경이 있으면 확인을 거칩니다). L5 행에서는 **연계 캔버스**(11장)도 열 수 있고, 플라이아웃 하단 **다른 체계 검색**은 전체 체계 탐색 모달을 엽니다. 시작·종료 노드만 있는 **새 빈 맵**을 열면 **"AI 컨설턴트로 시작하기"** 말풍선이 뜹니다 — **시작**을 누르면 인터뷰 화면(10장)으로 가고, **나중에**로 닫을 수 있습니다.

### 캔버스 이동

| 입력 | 동작 |
| --- | --- |
| 마우스 휠 | 세로 이동 (`Shift` + 휠은 가로 이동) |
| `Ctrl` + 휠 | 확대 / 축소 |
| `Space` 누른 채 드래그 | 화면 이동(팬) |
| 빈 캔버스 드래그 | 박스 선택 |
| 우클릭 | 컨텍스트 메뉴(노드·엣지·캔버스) |

### 우측 인스펙터 — Map / Approval 탭

노드를 선택하면 인스펙터에 그 노드의 속성이 보이고, 선택이 없으면 **Map / Approval** 두 탭이 나타납니다. 선택이 없는 동안 속성 자리에는 **소유·승인자 섹션**(오우닝 부서와 오너·승인자 — 표시 전용, 이름·부서는 언어 설정을 따라 표시)과 **맵 요약 아코디언**(기본 접힘 — 접힌 동안엔 헤더 우측의 아이콘+숫자 쌍이 요약을 대신)이 표시됩니다.

- **Map 탭** — 맨 위 버전 행에 **버전 필**(현재 버전과 상태 — 클릭해 다른 버전으로 전환)과 관리 아이콘이 있습니다(맨 왼쪽은 **버전 비교** 버튼 — 게시본이 없으면 비활성). 그 아래에 기본 접힘 섹션들이 있습니다: **Node display**(노드에 표시할 항목 — **속성/수행 지표/입출력 · 조건** 카테고리 계단 구성, 행 아무 곳이나 클릭해 토글. 같은 섹션이 속성 탭 기본 화면의 맵 요약 아래에도 나옵니다), **Edge style**, **Subprocess** 지정 카드(5장), **인터뷰 원문 메모**, **노트**. Edge style은 **모든 연결선의 선 모양을 일괄 변경**하며(확인 창이 변경 내역을 요약), 선택한 모양은 새로 그리는 연결선의 기본값이 됩니다. 개별 엣지는 엣지 선택 시 인스펙터나 우클릭 메뉴에서 따로 바꿀 수 있습니다. **인터뷰 원문 메모**는 컨설턴트 인터뷰 임포트가 남긴 원문 5종(GMP·연간 건수·소요시간·실작업시간·시스템)을 행으로 보여줍니다 — 행에 마우스를 올리면 행머리 아이콘이 노트 아이콘으로 바뀌고, 클릭하면 원문 팝오버가 열립니다. **편집 점유권을 가진 편집자**는 팝오버에서 원문을 고치거나 새로 남길 수 있고(`Ctrl`/`⌘+Enter` 저장, `Esc` 취소), 그 외에는 읽기 전용입니다. **노트**(예외 규칙·VOC·규정 근거·오픈 이슈 등)는 **맵 오너**가 추가·수정·삭제합니다 — 태그 프리셋 칩 또는 태그 입력창의 `[`로 태그를 고르고, 임포트된 노트를 고치면 **수정됨** 표시와 함께 출처가 유지됩니다(홈 맵 상세 카드에서도 같은 섹션이 보입니다). 협업자 목록은 개인 협업자가 4행을 넘으면 약 3.3행으로 접히고 **Show all (n)** / **Collapse** 토글로 펼치고 접습니다(협업자 추가·역할 변경 절차는 사용 안내 매뉴얼 참고).
- **Approval 탭** — 위에서부터: **Pending Approvals**(이 맵의 결재 대기 요청 — 대기 건수 배지, 기본 접힘) → 드래프트 CTA(드래프트가 있으면 **Switch to draft for approval**, 없으면 **Create draft for approval**) → **Approval workflow** 섹션(접을 수 있으며 접혀 있어도 헤더에 상태 배지 표시) → **Subprocess** 지정 카드 → 버전 카드 목록. 승인 진행은 7장과 사용 안내 매뉴얼을 보세요.

## 2. 노드와 연결

### 노드 만들기

캔버스를 우클릭해 도형을 고르거나, 인스펙터의 **Add node**를 사용합니다.

| 유형 | 모양 | 용도 |
| --- | --- | --- |
| **시작(Start)** | 알약 | 흐름의 진입점 — 시작 노드는 하나만 허용 |
| **프로세스(Process)** | 사각형 | 일반 단계·작업 |
| **판단(분기)(Decision)** | 마름모 | 분기 질문 — 출력을 여러 개 가질 수 있는 유일한 노드 |
| **종료(End)** | 알약 | 종료점 — 프로세스당 **대표 끝**은 정확히 하나 |
| **하위프로세스(Subprocess)** | 테두리 박스 | 다른 맵을 참조하는 단계 (5장 참고) |

시작·종료 노드의 이름을 바꾸면 노드에 **Start / End 타입 필**이 제목과 함께 표시되어 유형을 한눈에 알 수 있습니다. 시작·종료 노드의 설명(노트)은 캔버스에는 나오지 않고 인스펙터·노드 편집 창에서만 보입니다.

### 노드 속성

노드를 선택하고 우측 인스펙터에서 편집합니다:

- **제목**과 **설명** — 노드 **제목을 더블클릭**하거나 `F2`로 즉시 이름을 바꿀 수 있습니다. 제목 바깥의 노드 본체를 더블클릭하거나 우클릭 메뉴 **정보 수정**을 고르면 **노드 편집 창**이 열립니다(아래 참고). 인스펙터의 설명은 **읽기 전용** — 마우스를 올리면 나오는 편집 아이콘이나 내용 더블클릭으로, 설명에 포커스된 노드 편집 창이 열립니다.
- **노드 편집 창** — 제목·설명 아래에 필드가 **타일**로 놓입니다(서브프로세스 지정 모달과 같은 디자인, 폭 512px): 유형·색 타일, **속성**(부서·담당자는 두 열을 가로지르는 행 타일 — 부서는 말단 부서 필로 보이고 필을 누르면 조직 정보 모달, 시스템·링크·GMP), **수행 지표** 7종(비용은 한 타일 — 팝오버 앞의 ₩/$ 탭으로 단위를 고르고 타일에는 고른 단위가 필로 표시, 다른 통화 값은 저장 시 지워짐), **입출력 · 조건**(입력물·산출물은 항목 수만 보이고 팝오버에서 항목별로 편집, 자료 형식 폴백·시작/종료 조건). 타일을 클릭하면 **클릭한 자리에 입력 팝오버**가 열리고 `Enter`(여러 줄 편집기는 `Ctrl`/`⌘+Enter`)로 반영, `Esc`로 취소, 바깥 클릭은 변경이 있을 때만 반영합니다. 팝오버 하단 버튼은 변경이 없으면 **취소** 하나, 변경이 생기면 **저장**으로 바뀌며 ▾ 메뉴(저장 / 저장하고 닫기 / 저장하지 않고 닫기)가 붙습니다. 부서 피커 목록은 **내 부서 체인이 맨 위**에 오고 내 부서 행에는 **내 부서** 필이 붙으며(새 맵의 오우닝 부서 피커와 같은 모양), 부서를 바꾸면 담당자가 해제된다는 안내가 팝오버 안에 뜹니다. 팝오버에서 반영한 값과 제목·설명 타이핑은 **노드에 바로 반영**되어 오른쪽 인스펙터에도 즉시 보이고, 반대로 인스펙터에서 고친 값도 열려 있는 편집 창의 타일·팝오버에 바로 반영됩니다 - 하단은 **완료**(`Esc`)뿐이고 되돌리기는 `Ctrl+Z`입니다. 시스템 타일은 마우스를 올리면 아이콘이 **인터뷰 원문 메모** 아이콘으로 바뀌어(흰 칩 위에 표시) 메모를 보고·고치고·적용할 수 있고, 메모가 있는 타일은 호버 전에도 아이콘 모서리에 **작은 점**이 보입니다. 시스템 팝오버 안에도 메모 칸이 있습니다(서브프로세스 지정 모달의 소요시간·실작업·시스템·연간 건수 타일도 같은 호버 메모 아이콘·점). 입력물·산출물 팝오버 하단에는 **+ 추가** 옆에 **다른 노드에서 불러오기…**가 있습니다(인스펙터 카드와 같은 불러오기 창, 반영 안 된 초안이 있으면 잠김). **이전 / 이후 연결 노드**는 편집 창 밖 캔버스 좌우에 떠 있는 작은 카드(색 점·라벨·유형)로 보이며, 마우스를 올리면 카드가 편집 창 쪽으로 넓어지고 조금 높아지며(확대 변환이 아니라 실제 크기가 바뀌어 글자가 흐려지지 않음) 위아래 카드가 자연히 벌어집니다. 클릭하면 그 카드가 가운데로 커지며 들어오고 가운데 카드는 반대편 독으로 줄어드는 전환 애니메이션 뒤 그 노드 편집으로 넘어갑니다. 인스펙터의 BPM 속성 행도 다른 카드처럼 아이콘+라벨이며(시스템 행머리 아이콘이 호버 시 원문 메모 아이콘), 하위프로세스 노드의 연간 건수·FTE 행은 참고치 아이콘이 라벨 뒤, 입력이 맨 오른쪽에 같은 폭으로 놓입니다. 읽기 전용(뷰어·잠금·게시본)에서는 값 있는 타일만 정적으로 보이고, 입력물·산출물 타일만 클릭해 목록을 열람할 수 있습니다. 하위프로세스 노드의 편집 창은 링크 맵에서 상속하는 속성·회당 4지표·입출력/조건을 읽기 타일로 보여주고 **연간 건수·FTE**만 편집합니다(팝오버에 지정 참고치 안내). 이름 입력 중 `Enter`는 확정, **`Shift+Enter`(또는 `Alt+Enter`)는 줄바꿈**입니다 — 캔버스 인라인 편집·인스펙터·노드 편집 창 모두 같은 규칙이고, 줄바꿈은 캔버스에도 그대로 표시됩니다.
- **색상** — 프리셋 견본 또는 커스텀 hex 색상(`#RRGGBB`).
- **BPM 속성** — **담당자**(조직 디렉터리에서 선택), **부서**(담당자에 따라 자동 설정), **시스템**, 그리고 **회당 수행 지표**(3장 참고).
- **GMP 분류** — 노드를 **GMP Direct / GMP Indirect / Non-GMP**로 분류합니다. 분류는 노드 왼쪽 위 **필 태그**로 표시되고(표시 여부는 Map 탭 Node display의 GMP 행), 편집 모드에서 필을 클릭하면 그 자리에서 분류 피커가 열립니다. 분류를 고르면 **노드 색이 분류 색으로 자동 확정**되며(Direct=빨강, Indirect=앰버, Non-GMP=초록), 안내 창의 **이전 분류로 되돌리기 / 색만 되돌리기**로 취소할 수 있습니다. 미분류 노드의 필은 공간을 차지하지 않고 노드에 마우스를 올렸을 때만 나타납니다. 하위프로세스 노드는 링크한 맵의 GMP 지정값을 읽기전용으로 상속합니다.
- **입출력 · 조건** — **입력물**과 **산출물**은 항목을 여러 개(행마다 하나) 등록합니다. 행에 마우스를 올리고 작은 파일 아이콘을 누르면 그 항목의 **자료 형식**을 지정할 수 있습니다: 자동완성 목록이 확장자·영문 프로그램명·한글 어느 쪽으로도 매치되고(`.xlsx`/`Excel`/`엑셀` 모두 같은 항목), ↑/↓로 이동해 Enter 또는 Space로 선택합니다. 목록에 없는 값은 맨 아래 **"…" 추가** 행으로만 확정됩니다. 지정된 형식은 작은 필로 표시되며(카탈로그 항목은 아이콘 동반) 필 클릭=변경, ✕=제거. **시작/종료 조건**은 자유 텍스트. 노드 단위 *자료 형식* 행은 임포트 폴백으로, 항목별 형식이 하나도 없을 때만 표시됩니다. 캔버스에서는 입출력·조건 상자가 **노드를 선택했을 때** 노드 아래에 나타납니다(표시 항목은 Map 탭 Node display에서 선택).
- **다른 노드에서 불러오기** — 입력물/산출물 목록의 **Import from node…** 행으로 **연결된 흐름의 다른 노드가 가진 항목을 그대로 가져옵니다** — 입력물에는 상류 노드의 산출물이, 산출물에는 하류 노드의 입력물이 후보로 뜹니다. 가져온 항목은 원본과 **연결(Linked)** 상태가 되어 원본에서 고치면 함께 바뀌고, 미러 쪽에서는 직접 편집하는 대신 **연결 해제(Disconnect)**로 편집 가능한 복사본으로 떼어냅니다. 원본까지의 흐름 경로가 끊기면 항목에 경고가 표시됩니다.
- **연결 항목 표식과 하이라이트** — 다른 노드와 연결된(원본이든 미러든) 항목에는 **링크 아이콘**이 붙고, 방향 툴팁으로 어느 쪽이 원본인지 보여줍니다. 연결 항목 행에 마우스를 올리면 **상대 노드와 그 사이의 흐름 경로가 캔버스에서 함께 점등**됩니다 — 인스펙터 목록과 캔버스 노드 안의 입출력 행 어느 쪽에서든 동일합니다. 입력물 항목에는 **필수(Required) / 선택(Optional)** 플래그를 줄 수 있고, 행 호버 색(필수=붉은 톤)과 툴팁으로 구분됩니다. 항목이 **1개뿐인 입출력 상자**는 헤더 없이 행 하나로 표시되며, 체크박스 자리에 인풋/아웃풋 아이콘이 대신 나타납니다.
- **링크(URL)** — 노드에 외부 문서·시스템 링크를 달면 캔버스에 배지가 뜨고, 클릭해 미리보기·새 탭 열기를 할 수 있습니다. 표시 이름(라벨)을 따로 지정할 수 있습니다.

### 노드 연결

- 노드의 핸들을 드래그해 다른 노드에 놓으면 연결됩니다.
- 핸들을 정확히 겨냥하지 않아도 됩니다 — 드래그하던 선을 **노드 몸체 위에 놓으면** 기본 핸들로 바로 연결됩니다. 몸체 위에 있는 동안 연결될 위치가 미리보기로 스냅되어 보입니다.
- 일반 노드의 출력은 **하나**뿐입니다 — 분기하려면 **판단(분기)** 노드를 쓰세요. 판단 노드에서 나가는 엣지에는 분기 라벨(**Yes** / **No** / **기타**)이 붙습니다.
- 엣지 라벨(분기 조건 등)은 엣지 컨텍스트 메뉴나 `F2`로 편집합니다. 라벨도 `Enter` 확정 / **`Shift+Enter`·`Alt+Enter` 줄바꿈**으로 여러 줄을 쓸 수 있습니다.
- **선 모양은 엣지마다** 곡선 / 꺾은선 / 직선 중에 고릅니다 — 엣지를 선택하면 인스펙터의 **Line style**에서, 또는 엣지 우클릭 메뉴에서 바꿉니다. 선택한 모양은 맵에 저장돼 다른 사람에게도 같게 보입니다.
- 한꺼번에 바꾸려면 인스펙터 **Map 탭 → Edge style**에서 고르세요 — 몇 개가 바뀌는지 요약한 확인 창이 뜨고, 확정하면 전체에 적용되며 이후 새로 그리는 연결선의 기본값도 그 모양이 됩니다.
- 노드를 다른 노드 가까이 끌면 **드롭존**(**앞** / **뒤** / **자리 바꾸기(swap)** / **그룹**)이 나타나 한 동작으로 흐름에 끼워 넣거나 두 노드의 자리를 맞바꿀 수 있습니다.
- 이미 연결이 있는 노드에 엣지를 놓으면 **사이에 삽입**할지 **기존 유지**할지 묻고, **판단 노드**에 놓으면 **분기 추가** 또는 기존 출력에 **삽입**을 선택합니다.

### 노드 복사와 복제

- **복사/붙여넣기** — 노드를 선택하고 `Ctrl+C` / `Ctrl+V`. 선택 안의 연결(엣지)도 함께 복사되고, 같은 이름이 있으면 라벨에 `(2)`처럼 번호가 붙습니다.
- **다른 탭/다른 맵에도** 붙여넣을 수 있습니다 — 복사한 내용이 브라우저에 보관되어 탭을 오가며 씁니다.
- **`Ctrl`+드래그 복제** — 노드를 `Ctrl` 누른 채 끌면 잔상과 `+` 배지가 보이고, 놓는 위치에 복제본이 생깁니다.
- 붙여넣기·복제 모두 **엣지 핸들 방향(연결 지점)이 보존**되고, 추가된 노드는 곧바로 선택 상태가 되어 이어서 편집할 수 있습니다.

## 3. 회당 수행 지표

각 노드는 프로세스를 **한 번 수행할 때**의 비용·소요를 기록하는 7개 수행 지표를 가집니다. 인스펙터의 수행 지표 섹션(Metrics)(기본 접힘)에서 편집합니다. **수행 지표**와 **입출력 · 조건** 섹션의 편집은 바로 저장되지 않고 — 변경이 생기면 섹션 머리의 **저장(Save)** 버튼이 켜지며, 눌러야 반영됩니다. **시작·종료** 노드는 수행 지표가 없습니다.

| 수행 지표 | 라벨 | 입력 형식 | 캔버스 표시 |
| --- | --- | --- | --- |
| **소요시간** | 회당 소요시간(h) | `시.분` — 소수부는 **분** | `1h30m` |
| **실작업시간** | 회당 실작업시간(h) | `시.분` — 소요시간과 동일 규칙 | `1h30m` |
| **비용(원)** | 회당 추가비용(원) | 숫자 | `₩1,250,000` |
| **비용($)** | 회당 추가비용($) | 숫자 | `$1,200` |
| **투입인원** | 회당 투입인원 | 숫자 | 그대로 |
| **연간 건수** | 연간 건수 | 숫자 | 그대로 |
| **FTE** | FTE | 숫자 | 그대로 |

### 소요시간 표기 (시.분)

소요시간은 **시간과 분**으로 적습니다 — 소수부는 십진수가 **아니라 분**입니다.

- `2` → 2시간, `0.30` → 30분, `1.30` → 1시간 30분.
- 분이 60을 넘으면 시간으로 올라갑니다(`0.90` → 1시간 30분).
- 편집 중에는 입력한 `1.30` 형태로 보이고, 그 외 모든 화면에서는 `1h30m`으로 표시됩니다.

### 비용은 한 통화만

**원(₩)과 달러($)는 동시에 입력할 수 없습니다.** 비용은 **₩/$ 토글**이 달린 한 행으로 표시되며, 토글로 통화를 바꿉니다. 현재 통화에 이미 값이 있으면 저장 시 삭제된다는 안내가 뜨고 **되돌리기**로 전환을 취소할 수 있습니다. 비용에는 천단위 콤마가 자동으로 붙고, `1,250,000`처럼 콤마를 넣어 붙여넣어도 됩니다.

### 하위프로세스 노드의 수행 지표

하위프로세스 노드는 **연간 건수**와 **FTE**만 직접 입력합니다. 나머지 5개(소요시간·실작업시간·비용·투입인원)는 **링크한 맵의 지정값을 읽기전용으로 상속**하며, 부모 맵에서는 바꿀 수 없습니다(5장 참고). 링크한 맵이 지정 시 연간 건수·FTE **참고치**를 남겨 두었다면 해당 입력칸 옆 ⓘ에 마우스를 올려 "지정 참고치: …"를 볼 수 있습니다 — 참고일 뿐 이 노드의 값은 따로 가집니다.

### 합계 미리보기 (Σ)

맵을 하위프로세스로 지정할 때(사용 안내 매뉴얼의 맵 설정 참고), 지정 폼이 그 맵의 게시본 수행 지표를 **합산해 미리보기**로 제안합니다 — 소요시간·실작업시간·비용은 **합**, 투입인원은 값이 있는 일반 노드의 **평균**입니다.

## 4. 맵 정리하기

### 그룹

- **노드 2개 이상**을 선택하고 `Ctrl+G`(또는 우클릭 → **그룹 만들기**)로 묶습니다.
- 그룹 제목을 더블클릭해 이름을 바꾸고, 제목 바를 드래그해 그룹 전체를 옮기고, **그룹 해제**로 풉니다.
- **그룹 일괄 편집**은 상단 한 행의 카테고리 버튼 — **속성**(담당·부서, 시스템) · **수행 지표**(7필드) · **입출력 · 조건**(입력물·산출물·시작/종료 조건) — 으로 나뉩니다. 카테고리를 누르면 바로 아래에 필드 버튼이 펼쳐지고(다른 카테고리를 누르면 아래 내용이 교체), 필드를 골라 멤버 전체에 한 번에 설정/해제 — 추가 / 교체 / 건너뛰기 충돌 처리와 전후 요약 제공. 입력물/산출물은 **추가=기존 항목 아래 줄 추가**, **교체=항목 전체 덮어쓰기(항목별 자료 형식은 줄 짝이 깨져 함께 비워짐)**입니다. 비용 한 통화 규칙과 하위프로세스 노드의 편집 제한(연간 건수·FTE만 — 입출력/조건은 링크 맵 상속이라 제외)은 여기서도 그대로 적용됩니다.

### 정렬과 배치

- **자동 정렬**은 전체 흐름을 자동 배치합니다 — 가로(`Shift+L`, 좌→우) 또는 세로(`Shift+K`, 상→하). 시작→대표 끝 주 경로가 한 직선으로 정렬되고 분기는 옆으로 배치되며, 엣지 출입 방향도 함께 맞춰집니다.
- **`Shift`+드래그 — 축 고정 이동**: 노드(단일·다중·그룹)를 `Shift` 누른 채 끌면 수평 또는 수직 한 축으로만 움직여 줄 맞추기가 쉽습니다.
- 2개 이상 선택 시: **왼쪽 정렬** `Alt+W`, **가운데** `Alt+C`, **위쪽 정렬** `Alt+T`, **중간** `Alt+X`.
- 3개 이상 선택 시: **가로 균등 배치** `Alt+R`, **세로 균등 배치** `Alt+V`.
- **간격 자동 조정** — 입출력 상자 등으로 노드가 세로로 커지면, 그 노드와 **가로로 겹치는 열의 아래 노드만** 화면에서 밀려나 겹치지 않습니다. 커진 만큼은 먼저 저장된 여백이 흡수하고, 모자랄 때만 최소 간격(저장 간격 또는 16px 중 작은 값)을 유지하며 밀립니다 — 다른 열의 노드는 움직이지 않습니다. **표시만** 조정되는 것이라 저장된 좌표는 바뀌지 않으며, 노드가 다시 작아지면 원위치로 돌아옵니다. 꺾은선 연결선이 커진 노드를 관통하게 되면 자동으로 직각 우회 경로를 그립니다.

## 5. 하위프로세스 (맵 연결)

**하위프로세스** 노드는 다른 프로세스를 하나의 단계로 끼워 넣습니다 — 복사가 아니라 **참조**입니다.

- **하위프로세스 만들기**(프로세스 노드 우클릭)는 시작 / 작업 / 종료가 준비된 자식 맵을 생성합니다.
- **링크 노드로 추가**는 프로세스 라이브러리에서 기존 맵을 연결합니다. 새 링크는 기본으로 **최신 발행본을 자동 추종**하며, 원하면 특정 버전으로 고정할 수 있습니다. 더 새로운 게시 버전이 생기면 노드에 **최신으로 업데이트**가 표시됩니다.
- SP 목록은 우클릭 메뉴 또는 **`S` 단축키**로도 열 수 있고, 검색은 한글 **초성**을 지원합니다. **이미 이 맵에 링크된 맵은 중복으로 추가할 수 없습니다.**
- 라이브러리 피커에는 기본으로 **서브프로세스로 지정된 맵만** 나타납니다. 지정은 맵 소유자가 **맵 설정 → 서브프로세스 지정**에서 대표 어트리뷰트(부서 필수, 담당자·시스템·링크·회당 수행 지표 7종·입력물/산출물 선택 — 타일을 클릭해 그 자리 팝오버로 입력, 사용 안내 매뉴얼 5장)와 함께 설정하며, 이 값들은 그 맵을 링크한 모든 노드에 라이브로 표시됩니다. 설명은 별도로 두지 않고 **맵 설명**을 그대로 씁니다.
- 게시본을 연 상태라면 에디터 인스펙터의 **Subprocess** 카드(Map·Approval 탭 공통 — 본문 기본 접힘, 헤더 ⓘ에 호버 안내)에서도 오너/관리자가 지정을 관리할 수 있습니다. **Designate as subprocess** 버튼 행 우측에 상황 버튼이 함께 놓입니다 — 게시본이 아닌 버전을 보고 있으면 **Go to published version**, 오너가 아니면 **Request registration**(오너에게 등록 요청).
- **미지정** 맵을 가리키는 링크 노드는 경고 뱃지와 함께 잠기며, 맵이 지정되면 다시 풀립니다.
- **미리보기 피크** — 라이브러리 목록의 맵 행을 **클릭하거나 2.5초 호버**하면 그 맵의 **게시본 미리보기 피크**가 열립니다. 헤더 좌측에 맵 이름·오너·게시 버전, 우측에 **업무 체계 경로**(클릭하면 체계 트리 플라이아웃과 "다른 체계 검색")가 놓입니다. 좌측 흐름 미리보기(캔버스와 같은 타입색)는 **휠로 확대/축소**(100~300%, 커서 위치 기준)하고 드래그로 이동하며, 미리보기 위에 **맵에 추가**(강조색)·**해당 맵으로 이동** 버튼이 떠 있습니다. 우측은 **노드 / 상세** 두 탭 — **노드 탭**은 추가될 노드의 실물 목업(대표 속성·수행 지표 칩·GMP·조건·입출력 체크리스트, 마우스를 올리면 현재 맵의 표시 설정 기준으로 전환)으로, 목업을 **캔버스로 바로 드래그**해 놓을 수도 있습니다. **상세 탭**은 지정 속성·SP 수행 지표·조건/입출력/GMP·게시 버전(v번호)·게시 시각·업무 체계 경로를 보여줍니다(빈 값은 대시로 톤다운). 열람 권한이 없는 맵은 잠금 안내와 함께 추가만 할 수 있습니다. 목록의 **부서 칩**에 마우스를 올리면 커서 옆에 조직 정보 카드가 열립니다.
- **링크된 맵 열기** — 하위프로세스 노드를 우클릭하면 메뉴 맨 끝(구분선 아래)에 **링크된 맵 열기**가 있습니다. 링크가 없거나 열람 권한이 없으면 비활성이고, 누르면 에디터를 떠나기 전에 확인을 거칩니다(저장 안 된 변경 보호).
- **펼쳐 보기(인라인)** — 하위프로세스 노드를 우클릭해 **펼치기(Expand)**를 고르면(노드가 지정·미잠금 상태일 때) 자식 맵의 게시본이 현재 캔버스 위 **틴트 영역**으로 읽기 전용 임베드됩니다. 영역 상단 헤더에 맵 이름과 열기 아이콘이 있고, 링크맵이 업무 체계 소속이면 **5단계 전체 분류 경로 라벨**이 함께 표시됩니다(클릭하면 분류 피크가 열립니다). 영역에 마우스를 올리면 살짝 강조되고, 영역 안 우클릭 메뉴로 **링크맵 열기**(확인 게이트)와 **접기**를 쓸 수 있습니다. `Tab` 순회는 펼쳐진 자식 노드도 흐름 순서대로 포함하며, 자식 노드의 GMP 필은 읽기 전용으로 표시됩니다.
- **딥 뷰:** 하위프로세스 노드를 더블클릭하면 자식 맵이 브레드크럼과 함께 오버레이로 열립니다 — 임베드된 내용은 **읽기 전용**입니다. `Esc`로 한 단계 위로 나갑니다.
- **노드 폭 조절** — 하위프로세스 노드에 마우스를 올리면 우측 경계에 **그립**이 나타납니다. 드래그해 폭을 조절하면(기본 180px ~ 최대 120%) 맵에 저장되어 다시 열거나 다른 사람이 봐도 유지됩니다.
- **업무 체계 필** — 링크맵이 업무 체계(Framework)에 등록돼 있으면 노드 이름 옆에 폴더 모양 필이 붙습니다. 클릭(또는 3초 호버)하면 분류 경로 피크가 열리고, 하단 **"다른 체계 검색"**으로 전체 체계 탐색 모달로 이어집니다. 피크는 마우스가 잠깐 벗어나도 0.4초 유예 후에 닫혀 이동 중 끊기지 않습니다.
- 연결된 맵의 권한이 없으면 노드에 **No access**가 표시됩니다.
- **인스펙터 Subprocess 탭** — 서브프로세스로 지정된 맵을 열면 인스펙터에 **Subprocess 탭**이 나타납니다: **지정 정보**(버전·지정 시점·지정자) → **이 맵을 연결한 맵**(역참조 목록) → **지정 파라미터**(지정 모달과 같은 타일을 좁은 인스펙터에 맞춰 **한 열**로 — 부서(말단 부서 필, 클릭하면 조직 정보 모달)·담당자, 시스템·링크, 회당 지표, 입력물·산출물 항목 수; 정적 타일이고 입출력 타일은 클릭해 목록 열람). 값이 없는 항목도 회색 **미입력** 타일로 남아 무엇이 빠졌는지 보이고, 대표값 없이 인터뷰 원문 메모만 있는 항목은 메모를 **인터뷰 원문 기준** 표시와 함께 임시값(점선 테두리·기울임)으로 보여줍니다. 인터뷰 원문 메모가 있는 파라미터(소요시간·실작업시간·시스템·연간 건수)는 아이콘 모서리에 작은 점이 있고, 행에 마우스를 올리면 아이콘이 메모 아이콘으로 바뀌며 클릭하면 원문을 볼 수 있습니다. 오너·관리자가 게시본을 열었을 때는 섹션 헤더의 **수정** 버튼으로 지정 모달을 바로 엽니다. 게시본이 아닌 버전(draft 등)을 열었으면 지정 파라미터 위에 **게시본이 아닙니다** 워터마크가 깔리고 수정 자리에 **게시본으로 이동**(액센트 테두리) 버튼이 놓입니다(지정값은 게시본 기준). 맵 자체의 **Subprocess 지정 카드**에도 **Linked from**(이 맵을 링크한 맵 역참조) 아코디언이 있어, 지정된 맵이 어디에 쓰이는지 카드에서 바로 확인할 수 있습니다.

### 아직 등록되지 않은 맵 연결하기 (플레이스홀더)

서브프로세스로 **지정되지 않은 맵도 자리 표시(플레이스홀더)로 먼저 링크**해 두고, 등록은 나중에 처리할 수 있습니다.

- **프로세스 라이브러리 패널**(상단 바 라이브러리 버튼)의 검색 아래 **"Show unregistered maps"** 토글을 켜면 미등록 맵도 목록에 나타나고 **"Not registered" 배지**가 붙습니다.
- 미등록 맵도 다른 맵과 똑같이 **캔버스로 드래그**해 놓습니다 — 놓는 순간 경고 확인이 뜨고, 이어서 **등록 요청을 보낼지** 묻습니다: **Send request**는 링크+요청, **Link only**는 링크만.
- 등록 요청은 대상 맵 **오너의 Inbox(승인 대기)**로 갑니다. 오너가 지정을 완료하면 링크의 경고가 풀리고 요청자에게 알림이 옵니다(수락 절차는 사용 안내 매뉴얼 참고).
- 요청을 아직 안 보냈거나 상태를 보려면 — 미등록 링크 노드를 선택하면 인스펙터에 **Request registration** 버튼(요청 후엔 **Registration requested** 배지와 본인 요청 **철회** 버튼)이 나타납니다.
- **새 맵을 즉시 만들어 연결** — 라이브러리 패널에 검색어를 입력하면 맨 아래에 **"검색어"로 맵 만들기** 버튼이 나타납니다. 누르면 그 이름이 미리 채워진 생성 창이 뜨고(오우닝 부서·결재자 등 요건은 평소와 동일), 생성이 끝나면 홈으로 이동하지 않고 **현재 맵에 자동으로 링크**됩니다. 새 맵은 게시 후 서브프로세스로 지정해야 경고가 풀립니다.
- 상단 바 **맵 이름 드롭다운**에서는 서브프로세스로 지정된 맵이 **보라색 서브프로세스 아이콘**으로 표시되고, 이 맵에서 **사용 중인(링크된) 맵은 행 배경이 보라색으로 하이라이트**됩니다 — 사용 중인 맵을 클릭하면 메뉴가 펼쳐지면서 캔버스의 해당 노드로 **자동 포커싱**됩니다. 현재 맵은 목록에서 제외되며, 드롭다운은 바깥을 클릭하면 닫힙니다.

## 6. 노드 찾기와 흐름 따라가기

- **노드 검색** — `/`를 누르고 입력하세요. 한글 **초성 검색**을 지원합니다. 매치된 노드로 점프하며 강조됩니다.
- **아웃라인** — 좌측 레일에 전체 프로세스가 트리로 표시되고, 항목을 클릭하면 해당 노드로 이동합니다.
- **흐름 하이라이트** — 노드를 선택한 뒤 `]`로 강조 경로를 앞으로 늘리고 `[`로 줄이거나 뒤로 확장합니다.
- **흐름 따라 이동** — `Tab` / `Shift+Tab`으로 흐름상 다음 / 이전 노드로 포커스를 옮기며 화면이 따라갑니다.
- **댓글** — 노드마다 댓글 스레드가 있습니다. `Ctrl+Enter`로 전송합니다. 읽기 전용 사용자도 댓글은 남길 수 있습니다.

## 7. 저장과 검증

- 편집을 멈추면 약 2초 후 **자동 저장**됩니다. **저장** 버튼은 저장 중… / 저장됨 / 저장 실패 상태를 보여줍니다.
- 저장하지 않고 나가면 경고가 표시됩니다 — 먼저 저장하세요.
- **저장 체크리스트**를 통과해야 저장됩니다:
  - 시작 노드 **1개**
  - 대표 끝(종료) **1개**
  - 종료 이름 **중복 없음**
  - 잘못된 분기 없음 — 일반 노드의 출력은 **1개**뿐(여러 출력은 판단 노드만)
- 편집은 초안(#초안 / #반려됨)이고 내가 **체크아웃**을 쥐고 있을 때만 가능합니다. 다른 사람이 편집 중이거나 승인 진행 중이면 캔버스가 읽기 전용으로 잠깁니다(버전·승인은 사용 안내 매뉴얼 참고).
- 체크아웃 요청·이양 UI는 승인 탭 **Approval workflow** 패널의 **Checkout** 카드에 있고, **드래프트에서만** 조작할 수 있습니다. 반려 상태에서는 체크아웃 UI가 표시되지 않습니다 — **Withdraw**로 철회하면 드래프트로 복귀하며 체크아웃이 자동으로 다시 주어집니다.
- 내 권한을 낮추는 변경이 승인 대기 중이면 체크아웃과 승인 요청이 잠시 거부됩니다("Your permission change is still pending approval."). 요청이 결정된 뒤 새로고침하거나 버전을 전환하면 이어서 진행할 수 있습니다.

### 승인 탭에서 승인 진행하기

승인 절차 전반(누가 승인하는지, 게시·만료 규칙)은 사용 안내 매뉴얼이 다룹니다. 에디터 인스펙터에서 보이는 것만 요약하면:

- **Approval workflow 패널** — 승인자마다 **Approved / Pending / Rejected** 태그 필이 붙고, 필에 호버하면 처리 시각과 코멘트 툴팁이 열립니다. 승인자 이름을 호버/클릭하면 인물 카드가 열립니다. 진행 필(**n/m approved**), **Waiting on** 대기자 필, 반려 사유 라인, 동봉된 가시성 변경 필("Visibility change bundled → …")도 여기에 표시됩니다. 제출자·제출 시각·제출 코멘트는 호버 아이콘으로만 보여줍니다("Submitted by …"). 상단 스테퍼(**Submit → Review → Publish**)의 단계 라벨도 같은 태그 필 스타일입니다.
- **전이 모달 코멘트** — 제출·승인·게시·철회 모달에 선택 코멘트 입력란("Add a comment (optional)")이, 반려 모달에는 사유(**Reason**) 입력란이 있습니다. 승인·반려 모달에는 요청자의 제출 코멘트(**Requester comment**) 배너가, 제출 모달에는 직전 반려 사유(**Previous rejection**) 배너가 함께 표시됩니다.
- **코멘트 이력** — 버전 카드의 말풍선 카운트 버튼(0건이면 숨김)을 누르면 그 버전의 코멘트 이력 모달이 열립니다. 버전 카드를 **우클릭**하면 **Go to this version**(편집 중이면 전환 확인 모달을 거침)과 **View comments** 메뉴를 쓸 수 있습니다.
- **반려 배너** — 반려된 버전을 열면 에디터 상단에 에러 톤 배너가 나타납니다: **Rejected** 칩 + 반려자 필 + 반려 사유.
- **변경 요약** — 승인 탭의 승인자 아래에 **게시본 대비 변경 요약**이 표시됩니다. 평소엔 카운트 필이 달린 한 줄로 접혀 있고, 펼치면 노드별 변경과 연결선 증감(+N / −N / ~N)이 나옵니다 — 승인자가 게시본과 무엇이 달라졌는지 제출 전후에 확인하는 용도입니다.

## 8. 가져오기 (CSV · AI)

표나 문서로 정리된 프로세스를 붙여넣어 맵을 채울 수 있습니다.

### CSV 가져오기

- 상단 바 **가져오기(Import CSV)**로 엽니다. **템플릿 다운로드**로 빈 양식을 받아 채운 뒤 올리세요.
- CSV는 **21개 열**을 씁니다: `name`(필수), `description`, `assignee`, `department`, `system`, `duration`, `touch_time`, `cost_krw`, `cost_usd`, `headcount`, `annual_count`, `fte`, `input`, `input_flags`(입력물 항목별 필수/선택 플래그), `output`, `data_form`, `start_condition`, `end_condition`, `url`, `url_label`, `next`(선후 연결 대상). 열이 적은 이전 파일도 그대로 읽힙니다(열은 이름으로 매칭). `input`/`output`은 셀 안 줄바꿈으로 여러 항목을 적습니다.
- 가져오기는 **제목(name)으로 병합**합니다 — 같은 제목의 기존 노드는 색·댓글·그룹을 그대로 두고 값만 갱신하며, **빈 칸은 기존 값을 유지**합니다. CSV에 없는 새 제목은 노드로 추가됩니다.
- **담당자**는 이름으로 적으면 조직 디렉터리와 매칭됩니다. **비용은 원/달러 중 한쪽만**, **소요시간은 시.분** 규칙을 그대로 따릅니다(3장). 하위프로세스 노드가 상속하는 필드(수행 지표 5종과 입력물/산출물/조건/자료 형식)는 CSV로 넣어도 무시됩니다. 항목별 자료 형식은 앱 전용입니다 — CSV에는 해당 열이 없고, 항목 줄이 그대로면 임포트 병합이 기존 값을 보존합니다.
- 미리보기 탭에서 **추가 / 매칭 / 삭제** 요약과 경고를 확인한 뒤 적용합니다.

> **외부 AI로 CSV 만들기:** 가져오기 창의 **다른 AI에게 물어보기**로 프롬프트를 복사해, 문서와 함께 외부 AI(ChatGPT 등)에 붙여넣고 받은 CSV를 다시 여기에 붙여넣을 수 있습니다.

### CSV로 새 맵 만들기

맵 목록(홈)의 **New map** 옆 드롭다운에서 **Create from CSV**를 고르면, CSV를 드롭해 바로 새 맵을 생성합니다(사용 안내 매뉴얼의 맵 목록 참고).

### AI 제안 병합

AI 도우미가 만든 순서도 제안도 같은 방식으로 **제목 기준 병합**됩니다(id 보존) — 자세한 내용은 10장.

## 9. 내보내기 (PNG · Excel · CSV · Word)

우측 인스펙터의 내보내기 버튼(또는 우클릭 메뉴)에서 현재 맵을 파일로 저장합니다.

| 형식 | 내용 |
| --- | --- |
| **PNG** | 현재 캔버스를 2배 해상도 이미지로 — 모든 연결선이 검은 실선으로 출력. 캔버스 배경(도트 그리드) 위에 그려지고, 하단에 **맵 정보 카드**(맵 이름·오우닝 부서·오너·버전·게시일·업무 체계 경로)가 함께 담깁니다. `Ctrl+Shift+E`. |
| **Excel** | **형식 2종 중 선택** — ① 구조 정리형: 노드 표(담당자·부서·시스템·회당 수행 지표)에 분기 조건을 `[분기번호:라벨]` 주석으로 정리 ② **WBS형**: 하위프로세스를 레벨 컬럼으로 펼친 작업분류표. 내보내기 시 형식 선택 창이 뜨고, 비용은 통화별 열과 숫자 서식으로 저장됩니다. |
| **CSV** | 가져오기와 같은 21열 표 — 내보낸 CSV를 고쳐 다시 가져오는 왕복이 가능합니다. |
| **Word** | 도형 순서도가 그려진 `.docx` 문서 — 노드 링크(URL)는 하이퍼링크로 포함됩니다. |

> CSV·Excel은 캔버스 좌표·그룹처럼 표로 표현되지 않는 구조가 있으면 경고와 함께 내보냅니다. 아주 큰 맵은 행 상한에서 잘릴 수 있습니다.

## 10. AI 도우미

에디터 상단 바에서 **AI 도우미**를 엽니다(서버에서 AI가 활성화된 경우에만 보입니다).

- 자연어 설명으로 플로우차트를 **생성** — 노드·엣지·그룹과 BPM 속성(담당자·부서·시스템·회당 수행 지표)이 조직 디렉터리에 맞춰 채워집니다.
- **증분 편집** — 수정을 요청하면 기존 배치와 색·담당자·그룹은 유지됩니다. 노드 추가/삭제, 연결/연결 끊기, 두 노드 사이 삽입, 분기 라벨 변경, 노드 설명·입력물/산출물·시작/종료 조건·링크(URL) 설정을 지원합니다. 미리보기 확인 후 **맵에 추가(Apply)** 또는 취소(Discard).
- **분석**("문제 찾기"), **요약**, 단계별 **워크스루**(이전 / 다음 / 자동 재생).
- **사용법 질문** — 이 매뉴얼을 근거로 답합니다. 매뉴얼 밖 내용은 모른다고 답합니다.
- **여러 대화** — 대화는 서버에 저장되어 어느 기기에서든 이어집니다. 대화 바의 목록에서 이전 대화를 열거나 창 헤더의 **+** 아이콘으로 새 대화를 시작합니다. 대화 제목은 첫 질문에서 자동으로 만들어지고, 목록에서 대화를 삭제할 수 있습니다.
- **다른 맵의 대화** — 대화 목록의 "다른 맵 대화"에서 다른 맵에서 나눈 대화를 읽기 전용으로 열람할 수 있습니다. 이어서 입력하려면 "이 맵 열기" 버튼으로 해당 맵으로 이동합니다.
- **대화 저장과 시간** — 대화는 맵 단위로 서버에 저장되고 메시지마다 시간이 표시됩니다. 보관량은 관리자가 정한 상한(기본: 맵당 대화 20개·대화당 메시지 200개·마지막 활동 후 180일)까지이며, 초과분은 오래된 것부터 자동 정리됩니다. 긴 대화는 최근부터 로딩되고, 스크롤을 맨 위로 올리면 이전 기록이 이어서 로딩됩니다(로딩 중 기능 팁 노출).
- **입력 한도** — 질문은 한 번에 2000자까지. 입력창 위 오른쪽 **링**이 남은 분량을 보여줍니다(75% 주의, 90% 경고).
- **글자 크기** — 대화 바의 **− T +** 로 채팅 글자 크기를 조절합니다.
- `Ctrl+Enter`로 전송합니다. 생성·편집은 편집 권한이 필요하고, 분석·워크스루·사용법 질문은 읽기 전용 사용자도 쓸 수 있습니다.

### AI 컨설턴트 인터뷰

빈 맵을 **인터뷰**로 채우는 전용 화면입니다. 상단 바의 **헤드셋 아이콘**(AI 컨설턴트) 또는 새 빈 맵의 "AI 컨설턴트로 시작하기" 말풍선에서 들어가며, 서버에 AI가 켜져 있고 **편집 가능한 초안**이 있어야 합니다.

- **화면 구성** — 좌측은 인터뷰 진행에 따라 그려지는 **작업 맵 미리보기**, 우측은 대화 패널(경계를 드래그해 폭 조절)입니다. 미리보기의 노드를 클릭해 "이 노드에 대해 질문"으로 대화에 언급할 수 있습니다.
- **인터뷰** — AI가 단계별로 질문하고, 활동·분기처럼 후보가 있는 항목은 **선택지 버튼**으로 제시합니다. 답을 모르는 항목은 **TBD로 표시하고 넘어가기**로 건너뛸 수 있습니다. 대화는 서버에 저장되어 나중에 이어서 진행합니다.
- **문서 첨부(빠른 경로)** — 클립 버튼으로 SOP·업무 문서(여러 파일 또는 폴더째)를 첨부하면 AI가 읽고 인터뷰 대신 **"제안대로 그리기"**로 바로 초안을 그릴 수 있습니다. 첨부 문서는 대화 패널의 목록에서 제거할 수 있습니다.
- **체크포인트** — 인터뷰 단계마다 작업 맵이 체크포인트로 남고, 이전 체크포인트로 되돌아갈 수 있습니다. 되돌리면 그 이후 단계는 접혀 이력으로 남습니다.
- **적용** — 인터뷰가 끝나면 **수집한 항목(파라미터) 검토·적용**과 **초안에 병합**을 실행합니다. 작업 맵이 초안 버전에 제목 기준으로 병합되므로, 먼저 에디터에서 초안을 **체크아웃**해 두어야 합니다. **다시 시작**은 대화·수집 항목·첨부·작업 맵을 모두 버립니다(초안 버전 자체는 그대로).

## 11. 업무 체계 연계 캔버스 (L5)

업무 체계(Framework)의 말단 분류(L5)마다 **연계 캔버스**를 열 수 있습니다 — 그 분류에 속한 프로세스(L6)들이 **하위프로세스 노드로 전부 배치**된 특수 캔버스로, 프로세스 사이의 업무 연계를 연결선으로 표현합니다. 시작/종료 노드 없이 L6 노드 중심으로 구성되며(분기·끝 노드는 보조로 사용 가능), 일반 맵 목록에는 나타나지 않습니다. 캔버스는 일반 맵과 구분되도록 **차콜(어두운) 배경**이 기본이며, 우상단 **레벨 5 맵** 태그 옆 버튼으로 라이트 배경으로 전환할 수 있습니다(브라우저에 기억). 캔버스 위에는 브랜드 워터마크와 상태 스탬프(**Draft / Confirmed / Superseded**)가 함께 표시됩니다.

### 열람과 편집

- **열기** — 홈 Framework 트리의 L5 행에 있는 **연계 캔버스 버튼**, 또는 에디터 Framework 칩의 L5 행에서 엽니다.
- **편집 권한** — 시스템 관리자가 지정하는 **카테고리 권한자**만 편집합니다. 상위 분류(L1~L4)의 권한자는 하위 전체 L5 캔버스를 편집할 수 있습니다(하향 상속). 권한자가 아니면 읽기 전용으로 열립니다.
- **초안 열람 규칙** — 확정 전 **라이브 초안**은 그 분류(또는 상위 분류)의 권한자와 sysadmin에게만 보입니다. 그 외 사용자는 **최신 확정본**으로 들어가며, 확정본이 아직 없으면 "아직 확정본이 없습니다" 안내가 뜹니다. 상단에는 상태 배너가 표시됩니다 — **Draft**(앰버: 확정 전 라이브 작업본, 확정하면 열람자에게 공개), **Confirmed**(최신 확정본, 읽기 전용), **Superseded**(이미 대체된 과거 확정본 — 최신 확정본 라벨 안내). 배너는 닫을 수 있고, 맵에 다시 들어오거나 버전을 바꾸면 다시 나타납니다.
- **체크아웃** — 초안 편집은 일반 맵처럼 체크아웃 단일 작성자 규칙을 따릅니다. 소속 L6가 새로 생기면 편집 진입 시 **자동으로 보강**되어 "새 L6 N개 추가됨 (미배치)" 토스트가 뜹니다.
- **소속 L6 잠금** — 이 분류 소속 L6 노드는 캔버스에서 **삭제할 수 없습니다**(분류 데이터가 소스). 외부에서 가져온 노드는 삭제 가능합니다.
- **일반 맵 워크플로 없음** — 승인 요청·게시·결재자·협업자·이름 변경 요청·서브프로세스 지정은 캔버스에 없습니다(화면에서 숨겨지고 서버에서도 차단). 확정 스냅샷과 라이브 초안은 삭제할 수 없습니다.
- **분류 노트** — Map 탭 하단 **노트** 섹션은 이 분류(카테고리)의 노트입니다. 인터뷰 임포트가 남긴 **진입 / 흐름 / 오픈 이슈 / 작업 메모** 태그 노트가 여기 모이고, 카테고리 권한자와 sysadmin이 추가·수정·삭제합니다.

### 확정(Confirm)과 버전

- **확정 준비 상태(게이트)** — Approval 탭의 체크리스트 6종을 모두 통과해야 확정할 수 있습니다: **연결된 L6가 모두 배치됨 · 플레이스홀더 없음 · 끊긴 링크 없음 · 연결된 L6가 모두 게시됨 · 출구 없는 순환 없음 · 분기는 디시전 노드를 사용**(나가는 연결이 전부 병행(parallel) 팬아웃이면 예외). 미충족 항목의 **찾기**로 문제 노드로 이동하며, 하나라도 남아 있으면 확정 버튼이 비활성입니다.
- **누가 확정하나** — 초안을 **체크아웃한 사람**이 그 L5의 **직속 권한자**(또는 sysadmin)일 때 직접 확정합니다. 상위 분류(L1~L4) 권한자는 편집은 할 수 있지만 직접 확정 대신 **확정 요청**을 보냅니다(코멘트 선택) — 요청은 직속 L5 권한자와 sysadmin의 승인함으로 가고, 요청을 보내는 순간 **내 체크아웃은 자동 해제**되어 결정자가 편집·확정할 수 있게 됩니다. 결정 전에는 **철회**할 수 있으며, 결과는 **확정 승인 / 확정 거절** 알림으로 옵니다. 직속 권한자·sysadmin은 요청 대신 바로 확정하라는 안내를 받습니다.
- **변경 확정(Confirm changes)** — 현재 상태를 **확정(Confirmed)** 스냅샷으로 남깁니다(게시와 다른 별도 상태). 번호는 v1.0 → v1.1 … 로 올라가고, **메이저 버전**을 체크하면 v2.0처럼 메이저가 올라가며 **직전 메이저의 마이너 스냅샷이 정리(영구 삭제)**됩니다 — 확정 전 모달이 유지/삭제 대상을 보여줍니다.
- 레이아웃 이동만 있고 실질 변경이 없으면 확정할 수 없습니다("이후 변경 없음"). 확정 섹션에는 직전 확정 이후의 **변경 요약**(노드·연결 증감)이 표시됩니다.
- 확정 스냅샷은 버전 드롭다운에서 읽기 전용으로 열람하고, **비교 화면**에서 스냅샷끼리 비교합니다. 버전 타임라인에서는 같은 메이저의 스냅샷들이 그룹으로 접히고, 최신 확정본에는 **최신 확정** 라벨이 붙습니다.

### 다른 분류의 프로세스 가져오기

- 좌측의 **L5 탐색기**(트리)에서 다른 분류를 펼쳐 L6 카드를 **캔버스로 드래그**하면 외부 L6 노드가 추가됩니다 — 뉴트럴 바디에 **좌측 색 탭과 출신 배지**(홈 L5 색)로 구분됩니다. 출처 배지를 클릭하면 그 L5의 **드릴인 피크**가 열립니다.
- 드릴인 피크의 **"다른 체계 검색"** 버튼은 전체 체계 **탐색 모달**을 엽니다 — 현재 경로가 펼쳐진 트리에서 형제 분류를 탐색하고, 분류·맵 이름으로 검색하며, 맵을 클릭해 이동할 수 있습니다(에디터 이탈은 확인 게이트를 거칩니다).

### 플레이스홀더와 링크 교체

- **플레이스홀더** — 아직 시스템에 등록되지 않은 L6의 자리는 **점선 에러 톤 노드**로 표시됩니다. 하단 배너의 **Connect a map**으로 연결 다이얼로그를 열면 출처 L5의 후보가 유사도 순으로 나오고(정확 일치 배지), 트리 탐색으로 다른 L5의 맵도 고를 수 있습니다 — 안내된 L5 밖의 맵을 고르면 경로 비교 확인을 거칩니다.
- **스테일 링크 교체** — 링크된 맵이 휴지통으로 가거나 복사본으로 대체(은퇴)되면 노드가 같은 점선 에러 룩으로 바뀌고 **Replace map** 배너가 나타납니다. 원본을 대체한 **후계자 맵이 추천 카드**로 고정 노출되어 한 번에 교체할 수 있습니다.
