# Business Process Map — 사용 안내

> Business Process Map(BPM)은 업무 프로세스를 플로우차트로 그리고, As-Is / To-Be **버전**으로 관리하며, **승인 워크플로**로 확정하는 웹 서비스입니다.

이 매뉴얼은 로그인부터 맵 관리·버전 승인·설정·협업까지 **편집 외의 전반적인 사용법**을 다룹니다. 캔버스에서 노드를 그리고 편집하는 방법은 **맵 편집** 매뉴얼을 함께 보세요. 시스템 관리자는 **관리자 매뉴얼**도 읽어 주세요.

---

## 1. 시작하기

### 로그인

1. 앱에 접속해 **Sign in with Keycloak**을 클릭하면 사내 SSO 계정으로 로그인됩니다. 한 번 로그인해 두면 다음 방문부터는 자동으로 로그인되고, 처음 열려던 화면(딥링크)으로 이어집니다.
2. 서버가 사내 계정(LDAP) 인증으로 운영되는 환경에서는 Keycloak 버튼 대신 **아이디/비밀번호 입력 화면**이 나옵니다 — 사내 계정 또는 관리자가 발급한 로컬 계정으로 로그인합니다.
3. 개발 환경에서는 **Sign in with a test account**로 테스트 사용자를 골라 로그인할 수 있습니다.

### 화면 한눈에 보기

| 화면 | 위치 | 역할 |
| --- | --- | --- |
| **맵 목록(Maps)** | 상단 탭 | 전체 프로세스맵 — 검색·생성·열기 |
| **공지사항(Notices)** | 상단 탭 | 관리자가 게시한 공지 |
| **알림·승인(Inbox)** | 상단 탭 | 내가 처리할 승인 요청과 알림 |
| **사용 매뉴얼(Manual)** | 상단 바 | 매뉴얼 문서들(한/영) — 제목 드롭다운으로 선택, 목차와 본문 검색 지원 |
| **피드백(Feedback)** | 상단 바 | 버그·제안을 관리자에게 전송 |
| **설정(Settings)** | 상단 바 | 내 그룹, 삭제 예정(휴지통), 관리자 콘솔 |

> **팁:** 맵 목록과 이 매뉴얼에서 `/` 키를 누르면 바로 검색창으로 이동합니다.

### 맵에서의 역할

| 역할 | 할 수 있는 일 |
| --- | --- |
| **Owner** | 전부 — 편집, 협업자·결재자·공개 범위 관리, 삭제 |
| **Editor** | 맵과 초안 버전 편집 |
| **Viewer** | 읽기 전용 — 열람, 비교, 댓글 |
| **결재자(Approver)** | 승인 요청된 버전의 검토·승인/반려 |

맵마다 **오우닝 부서(Owning department)**가 있으며, 그 부서에 속한 사람은 자동으로 **Editor** 권한을 갖습니다(2장 맵 만들기 · 5장 맵 설정).

공개 범위가 **공개(Public)**인 맵은 누구나 볼 수 있고, **비공개(Private)** 맵은 협업자와 결재자만 볼 수 있습니다. 볼 권한이 없는 비공개 맵으로 이동하면 접근 불가 안내가 표시됩니다.

## 2. 맵 목록 (홈)

### 홈 대시보드

홈 우측에는 **현황 대시보드**가 있습니다 — 맵 상태 **도넛 차트**, **최근 열어본 맵**, **내가 처리할 승인** 카드로 오늘 할 일을 한눈에 봅니다.

### 맵 찾기

- **좌측 조직도** — 부서 트리를 아코디언으로 펼쳐 부서별 맵을 탐색합니다. **나의 부서**는 즐겨찾기로 맨 위에 고정됩니다.
- 목록 위 토글로 **부서(Departments)** 보기와 **업무 체계(Framework)** 보기를 전환할 수 있습니다 — 전사 프로세스 분류 체계 트리로 맵을 탐색하는 보기로, 현재 시범 운영 중입니다.
- **최근 열어본** 밴드에 마지막으로 작업한 맵이 표시됩니다 — **Show more** / **Collapse**로 펼치고 접습니다.
- **All maps**에는 내가 볼 수 있는 모든 맵이 나옵니다. `/` 키 또는 검색창(**Search maps**)으로 이름을 필터링하세요.
- 필터 칩으로 **상태**(초안 / 검토 대기 / 승인됨 / 반려됨 / 게시됨)와 내 **역할** 기준으로 좁힐 수 있습니다. **Clear filters**로 초기화합니다. 화면이 좁으면 필터 필이 자동으로 축약됩니다(전체 라벨 → 짧은 라벨 → 아이콘).
- 카드를 클릭하면 **상세 패널**이 열립니다: 소유자, **오우닝 부서**, 노드 수, 열람 가능 멤버(개인 / 팀 / 유저그룹), 버전별 이력(생성·승인요청·승인·반려·게시·회수). 서브프로세스로 지정된 맵에는 **SP 배지**가 붙습니다. 버전 이력의 항목은 우클릭 메뉴(**Go to this version** · **View comments**)와 코멘트 말풍선 버튼을 지원하고(3장), 편집 권한이 있으면 카드에서 바로 협업자를 추가/제거할 수도 있습니다 — 설정과 같은 스택 저장·Undo 방식이며, 오너와 오우닝 부서 행은 보호됩니다(5장).

### 맵 만들기

1. **New map**을 클릭합니다.
2. 이름과 설명을 입력하고 **공개 범위**(공개 / 비공개)를 선택합니다.
3. **오우닝 부서**를 지정합니다(필수) — 실제 조직 부서여야 하며, 그 부서에 속한 사람은 이 맵의 Editor 권한을 항상 갖습니다. 피커는 **조직도 트리**를 들여쓰기로 탐색하며, 내가 속한 부서는 맨 위에 고정됩니다.
4. 필요하면 **초기 협업자**를 추가합니다 — 개인·팀·유저그룹을 Viewer 또는 Editor로. 목록이 비어 있으면 초대 안내 문구가 표시됩니다.
5. **결재자를 1명 이상** 지정합니다 — 결재자 없이는 맵을 만들 수 없습니다.

새 맵에는 **시작·종료 노드가 자동으로 만들어져** 바로 흐름을 그리기 시작할 수 있습니다. 에디터에서 다른 맵을 연결하다가 그 자리에서 새 맵을 만들 수도 있습니다(맵 편집 매뉴얼 5장 "플레이스홀더").

> **CSV로 새 맵 만들기:** **New map** 옆 드롭다운에서 **Create from CSV**를 고르면 CSV 파일을 드롭해 노드가 채워진 맵을 바로 만듭니다. CSV 형식과 규칙은 **맵 편집** 매뉴얼의 "가져오기"를 참고하세요.

### 복사와 삭제

- **Copy**는 맵 전체를 새 이름(중복 불가)으로 복제합니다.
- **삭제**하면 맵이 휴지통으로 이동합니다. **설정 → 삭제 예정**에서 **7일 이내** 복구할 수 있고, 이후에는 영구 삭제됩니다.

### 인물 카드와 조직 정보

- 버전 이력·결재자·허용 인원 등에 보이는 이름에 잠시(0.7초) 마우스를 올리거나 클릭하면 **인물 카드**가 열립니다 — 한/영 이름, 직급·보직, 소속 부서와 조직 경로, **메신저 열기(Open messenger)** 버튼을 제공합니다. 이름을 우클릭하면 **Send message**(메신저 보내기)·**Info** 메뉴를 쓸 수 있습니다.
- 허용 인원 목록의 부서(오우닝 부서 포함) 카드를 클릭하면(좌/우클릭 동일) **조직 정보 모달**이 열립니다 — 구성인원(**Members**)과 하위 조직(**Sub-organizations**) 아코디언을 보여주고, 상단 경로를 눌러 상위 조직으로 이동합니다. 부서 행 우클릭 메뉴에는 **Org info**가 있습니다.
- 이름 표기는 **언어 설정**을 따릅니다 — 한국어면 한글 이름을 먼저 보여주고, 한글 이름이 없으면 영문 이름으로 대체합니다.

## 3. 버전과 승인 워크플로

### 버전 모델

하나의 맵은 여러 **버전**(As-Is, To-Be, 자유 라벨)을 가집니다. 새 버전은 기존 버전의 전체 복사본으로 시작합니다. **초안은 한 번에 하나**만 진행할 수 있고, 새 버전은 현재 버전이 게시된 뒤에만 만들 수 있습니다. 새 버전을 만들 때 **이름은 직접 입력**하며(자동으로 "To-Be"가 채워지지 않습니다), **버전 번호는 게시 시점에 자동으로 부여**됩니다 — 입력칸 힌트로도 안내됩니다.

### 상태

| 상태 | 의미 |
| --- | --- |
| #초안 | 편집 중 — 체크아웃 보유자만 수정 가능 |
| #검토대기 | 승인 요청됨 — 캔버스 읽기 전용 |
| #승인됨 | 모든 결재자가 승인 — 게시 가능 |
| #게시됨 | 모두가 보는 현재 버전 |
| #반려됨 | 결재자가 반려 — 사유와 함께 작성자에게 반환 |
| #만료됨 | 더 새로운 버전이 게시되며 대체됨(최종 상태) |

### 체크아웃 (단일 작성자)

- 초안은 한 번에 한 사람에게 **체크아웃**됩니다. 다른 사람에게는 "{이름} 편집 중 — 읽기 전용" 배너가 표시됩니다.
- **체크아웃 요청**으로 현재 보유자에게 편집권을 요청하면, 보유자가 알림·승인함에서 승인/거절합니다.
- **체크아웃 이전**으로 보유자가 다른 편집자에게 직접 편집권을 넘길 수 있습니다.
- **30분** 동안 활동이 없으면 체크아웃이 자동 해제됩니다.

### 초안에서 게시까지

1. **결재자가 지정되어 있는지** 확인합니다(맵 설정 → 결재자) — 결재자 없이는 승인 요청을 할 수 없습니다.
2. **승인 요청** — 확인 모달에 검토할 결재자 명단이 표시되고, **코멘트(선택)**를 남길 수 있습니다("Add a comment (optional)"). 직전에 반려된 적이 있으면 **이전 반려(Previous rejection)** 사유 배너가 함께 표시됩니다. 제출하면 버전이 #검토대기 상태가 되고 잠기며, 모든 결재자에게 알림이 갑니다.
3. 결재자가 **승인** 또는 **반려**합니다 — 승인/반려 모달에는 제출자의 **요청자 코멘트(Requester comment)** 배너가 보이고, 반려는 **사유(Reason)**가 필수입니다. 반려 사유는 버전에 표시되고, 제출자에게 가는 거절 알림 말미에도 동봉됩니다. 승인은 **만장일치** — 모든 결재자가 승인해야 합니다.
4. 승인된 버전을 **게시**합니다(코멘트 선택 입력). 직전 게시 버전은 자동으로 #만료됨 처리됩니다.
5. **회수**는 검토 대기(Pending)·승인됨(Approved) 버전을 초안으로 되돌립니다(승인 기록 초기화) — **제출자만** 할 수 있습니다. 반려된(Rejected) 버전은 제출자 외에 맵 오너·sysadmin도 회수할 수 있으며, 회수한 사람이 편집권(체크아웃)을 갖습니다. 회수 모달에도 코멘트(선택)를 남길 수 있지만, **아직 아무 결정(승인·반려)이 없는** 검토 대기 버전을 바로 회수하면 이번 제출 기록이 코멘트와 함께 이력에서 사라집니다. **재게시**는 게시/만료된 버전에서 새 초안을 만들어 사이클을 다시 시작합니다.

> **단계별 코멘트와 코멘트 이력:** 제출·승인·게시·회수 모달에서 남긴 코멘트는 버전 이력에 함께 저장됩니다. 코멘트가 있는 버전은 버전 카드(맵 설정 → 버전)와 버전 타임라인(홈 맵 상세·인스펙터 맵 탭)에 **말풍선 카운트 버튼**이 표시되고(0건이면 숨김), 누르면 그 버전의 **코멘트 이력(Comments)** 모달이 열립니다. 버전 항목을 **우클릭**하면 **Go to this version**(이 버전으로 가기)·**View comments**(코멘트 보기) 메뉴도 쓸 수 있습니다.

> **공개 범위 동봉(오너 전용):** 맵 오너는 승인 요청 모달의 **Visibility** 드롭다운으로 공개 범위 변경을 버전 승인에 **동봉**할 수 있습니다 — "Visibility will change: … → …" 예고 줄이 표시되고, 버전이 게시되는 순간 함께 적용됩니다. 버전이 반려·회수되거나 삭제되면 동봉된 변경도 함께 종결됩니다. 동봉된 요청은 결재 대기 목록에 **"Decided with version approval"** 읽기전용 행으로만 표시되어 별도로 승인/반려할 수 없습니다.

> **셀프 게시(승인자가 나 혼자일 때):** 결재자가 **본인 1명**이면 승인 요청 버튼을 눌렀을 때 **"바로 게시할까요?" Yes/No 팝오버**가 뜹니다. **Yes**는 승인요청→승인→게시를 원클릭으로 끝내고, **No**는 일반 제출(승인 대기)로 남깁니다. 에디터와 맵 설정 → 버전 탭 양쪽에서 동일하게 동작합니다.

우측 인스펙터 하단의 **승인 대시보드**에 진행 단계(요청 → 검토 → 게시), 결재자별 체크 상태, 가능한 액션이 표시됩니다. 이 맵이 서브프로세스로 지정돼 있으면 승인 탭에 **지정 카드**(지정 상태·대표 어트리뷰트)도 함께 보입니다. 승인 탭과 맵 설정의 승인 대기 탭에는 이 맵으로 온 **결재 대기 목록**도 통합되어 있습니다 — 공개 범위 변경(Visibility change) · 권한 강등(Permission downgrade) · 맵 이름 변경(Map rename) · 서브프로세스 등록(Subprocess registration) 4종을 행별로 **Approve / Reject** 처리합니다. 상단 **Inbox** 탭에는 내가 처리할 대기 건수 배지가 붙습니다.

## 4. 버전 비교

에디터 상단 바의 **비교**를 엽니다(게시된 버전이 1개 이상 필요). 인스펙터 Map 탭의 버전 행에 있는 비교 버튼으로도 열 수 있습니다.

- **기준(Base)**과 **대상(Target)** 버전을 고릅니다 — **Swap**으로 서로 바꿉니다.
- 차이가 색으로 강조됩니다: **추가**(초록), **삭제**(빨강), **변경**(노랑). 노드 속성뿐 아니라 **연결선 라벨 변경**도 노랑으로 표시됩니다. "변경: 필드" 상세와 요약 줄도 제공됩니다.
- 연결선은 맵에 저장된 **선 모양(곡선/꺾은선/직선)** 그대로 그려집니다.
- **가로 배치** / **세로 배치** 토글로 두 캔버스의 배치를 바꿉니다.
- 겹쳐 보이는 노드는 **드래그로 잠시 옮겨** 볼 수 있습니다 — 화면 정리용 임시 이동이라 저장되지 않고, 버전이나 배치를 바꾸면 원위치로 돌아갑니다.
- **변경 목록**은 전체 / 노드 / 엣지로 필터링되고, **속성** 패널은 선택한 노드의 필드(회당 수행 지표·GMP·입출력/조건 포함)를 나란히 보여줍니다. 연결선을 선택하면 라벨·선 모양 변화가 보입니다.
- **요약(Summary) 탭**은 두 버전 전체를 숫자로 비교합니다 — 7개 회당 수행 지표의 버전 합계(기준 → 대상, 증감)와 값을 가진 노드 목록(클릭하면 캔버스에서 포커스), 그리고 **구조**(노드·엣지 수) · **시스템** · **부서·담당자**(지정률) · **GMP** 분포 섹션. 우상단 **요약 항목(Summary items)** 드롭다운으로 표시할 섹션을 고릅니다.
- **To-Be 적용**으로 대상의 변경을 반영하고, **내보내기**로 비교 결과를 PNG로 저장합니다 — 하단에 맵 이름·버전(기준 → 대상)·게시일이 담긴 정보 카드가 함께 담깁니다.

## 5. 맵 설정

에디터에서 **맵 설정**을 엽니다. 탭:

- **상세** — 이름과 설명. **이름 변경은 오너(또는 관리자)만 즉시** 적용됩니다 — 편집자가 이름을 바꾸면 **변경 요청**이 만들어져 오너의 Inbox로 가고, 결정 전까지 "요청 대기" 배지가 표시되며 본인 요청은 철회할 수 있습니다. 오너가 직접 이름을 바꾸면 대기 중이던 요청은 자동으로 정리됩니다.
- **오우닝 부서** — 맵의 오우닝 부서 지정/변경(Owner·sysadmin 전용). 부서원은 자동으로 Editor 권한을 가지며, 부서를 바꾸면 파생 Editor도 새 부서를 따라갑니다. 피커는 **조직도 트리**를 들여쓰기로 탐색하며, 내가 속한 부서는 맨 위에 고정됩니다.
- **협업자** — 개인·팀·유저그룹을 Viewer / Editor로 추가. 변경은 바로 적용되지 않고 **쌓아 두었다가**(To add / Change / Remove 필) **Save changes**로 일괄 적용하고 **Discard**로 전부 취소합니다. 각 필에는 저장 시 **즉시 적용**(⚡ 번개, "Applies immediately on save")인지 **승인 필요**(모래시계, "Needs approval after save")인지 예고 아이콘이 붙습니다 — 추가와 Viewer 대상 변경은 즉시 적용되고, **Editor 제거·Editor→Viewer 강등은 승인**을 거칩니다(오너가 직접 하면 모두 즉시). 승인이 필요한 변경은 해당 행에 **Approval pending** 태그(요청자 표시)로 모두에게 보이고, 본인이 낸 요청은 호버 시 **Withdraw** 필로 그 자리에서 회수할 수 있습니다. 대기 중인 요청과 겹치는 중복 요청은 차단되며, 오너가 직접 적용하면 대기 요청은 자동 종결됩니다. 저장 직후에는 **Undo** 버튼으로 직전 저장 1회분을 되돌릴 수 있습니다(항목별 예고 아이콘이 있는 확인 모달, 페이지를 떠나면 소멸).
- **결재자** — 결재자 명단 관리(버전이 승인 진행 중이면 잠김).
- **공개 범위** — 공개 / 비공개. 전환을 고르면 영향 미리보기(예: 공개 전환 시 기존 Viewer 권한이 승인 시점에 정리된다는 안내)와 함께 **Apply change** 확인 단계를 거칩니다. 변경에는 **승인이 필요**합니다 — 에디터 인스펙터의 전환 모달에는 결정할 수 있는 **승인자 명단**("Approvers who can decide")이 표시되고, 승인자가 0명이면 진행할 수 없습니다. 결정 전까지 **Approval pending**으로 표시되며 **Withdraw request**로 회수할 수 있습니다.
- **서브프로세스 지정** — 이 맵을 다른 맵의 하위프로세스로 쓸 수 있게 지정하고, 대표 어트리뷰트(부서 필수, 담당자/시스템/소요시간·비용·투입인원·**설명** 선택)를 설정합니다. 지정 값은 이 맵을 링크한 모든 노드에 라이브로 표시됩니다. **지정에는 게시된 버전이 필요**합니다.
- **버전** — 버전별 워크플로 액션(승인 요청, 게시, 회수 등).
- **승인 대기** / **체크아웃 요청** — 이 맵으로 온 요청을 처리합니다. 승인 대기 탭에는 공개 범위 변경·권한 강등·맵 이름 변경·서브프로세스 등록 4종이 모여 행별로 **Approve / Reject**하며, 버전 승인에 동봉된 요청은 **"Decided with version approval"** 읽기전용 행으로만 표시됩니다.
- **위험 구역** — **소유권 이전**(나는 편집자로 내려감)과 **맵 삭제**(Owner 전용).

## 6. 공지사항 · 알림·승인 · 피드백

### 공지사항

**공지사항** 탭에 현재 게시 중인 공지가 나옵니다. 전체 / 중요 / 일반 필터, 검색, **읽음 처리**를 지원하며 본문은 마크다운으로 표시됩니다. 읽음 표시는 **이 브라우저(기기)에만 저장**됩니다 — 다른 기기·브라우저에서 열면 다시 안 읽음으로 보입니다.

### 알림·승인

- **승인 탭** — 내가 처리할 검토 큐: 버전 승인, 체크아웃 이전, 권한·공개 범위 요청, **맵 이름 변경**, **서브프로세스 등록 요청**. 항목에서 바로 승인/반려(사유 입력)하고 **맵 열기**로 원본으로 이동합니다. 상단 **Inbox** 탭에는 내가 처리할 대기 건수 배지가 붙습니다(주기적으로 갱신). 버전이 반려되면 거절 알림 말미에 반려 사유가 함께 담깁니다. 점유권 이전·권한/공개 범위 변경은 요청과 결과가 알림 탭에도 그대로 병행 표시됩니다. 아무 항목도 선택하지 않으면 우측에 **활동 다이제스트**가 요약을 보여줍니다.
- **서브프로세스 등록 요청 처리(오너)** — 누군가 내 맵을 미등록 상태로 링크하고 등록을 요청하면 **"Subprocess registration" 카드**가 옵니다(누가, 어느 맵에서 요청했는지 표시). **Designate & approve**를 누르면 지정 폼(부서 필수)이 열리고, **저장하는 순간 요청이 승인 처리**되며 요청자에게 알림이 갑니다. **Go to published version**으로 게시본을 먼저 검토할 수 있고, **게시된 버전이 없는 맵은 지정할 수 없어** 먼저 게시하라는 안내가 표시됩니다. **Reject**는 사유 없이 반려하며 요청자에게 알림이 갑니다.
- **벨 알림** — 우측 상단 벨은 **5초 간격**으로 갱신됩니다. 항목을 클릭하면 **알림 탭**으로 이동해 해당 알림이 열리고(자동 읽음 처리), 벨에서 바로 읽음 처리·개별 삭제(X)도 할 수 있습니다. 버전 승인 진행, 점유권 이전 요청/승인/거절, 권한·공개 범위 변경 요청/승인/반려가 모두 벨로 옵니다.
- **알림 탭** — 벨과 달리 **페이지 진입 시 한 번 로드**됩니다(자동 갱신 없음 — 최신 내역은 새로고침으로 확인). **모두 읽음**, 카테고리 필터(전체/버전/점유권/권한/공지), 항목별 삭제(X)에 더해 **선택 모드**로 여러 건 체크해 삭제, **읽은 알림 일괄 삭제**, **날짜 지정**(그 날짜 00:00 이전) 일괄 삭제를 지원합니다. 일괄 삭제 3종은 확인 모달을 거치며, **모든 삭제는 되돌릴 수 없습니다**.
- **보존**: 알림은 1인당 **최근 100건**만 보관됩니다 — 초과분은 읽음 여부와 무관하게 오래된 것부터 자동 삭제됩니다.

### 피드백

어느 화면에서든 **피드백**을 클릭해 유형(**버그 / 제안 / 질문 / 기타**)을 고르고 내용을 보내세요 — 현재 화면과 열려 있는 맵이 자동으로 첨부됩니다. 처리 상태와 관리자 답변은 **피드백** 페이지에서 확인합니다.

- **노트** — 목록 오른쪽 끝 노트 버튼을 누르면 그 피드백에 **누구나 메모를 남길 수 있는** 창이 열립니다(재현 조건, 진행 상황 등). 남긴 노트는 시간순 기록으로 쌓이고, 본인 노트는 나중에 고칠 수 있습니다 — 고쳐도 **이전 내용이 이력으로 남고**, 지우면 삭제가 아니라 **보관 처리**되어 "아카이브 보기"로 다시 볼 수 있습니다.
- **알림** — 답변이 달리거나 상태가 바뀌면 관리자가 알림을 보내 줍니다(자동 발송이 아니라 관리자가 확인 후 보냅니다). 알림은 상단 종 아이콘과 **받은함**에서 확인합니다.

## 7. 유저그룹

그룹을 쓰면 여러 사람에게 맵 권한을 한 번에 부여할 수 있습니다.

- **그룹 요청**(설정 → 그룹): 이름, 설명, **멤버 2명 이상**, **매니저 1명 이상**(★)을 입력합니다. 관리자가 승인해야 그룹이 활성화됩니다.
- 매니저는 멤버 추가/제거, 매니저 지정, 이름 변경(주 1회), 비활성/재활성, 그룹 삭제를 할 수 있습니다. 삭제된 그룹은 7일간 휴지통에 보관됩니다.
- 내가 속하거나 관리하는 그룹만 보입니다.

## 8. 자주 묻는 질문

- **편집이 안 돼요.** 다른 사람이 체크아웃 중이거나, 승인 진행 중이거나, 내 역할이 Viewer일 수 있습니다. 캔버스 상단 배너를 확인하세요.
- **승인 요청이 안 돼요.** 먼저 결재자를 1명 이상 지정하세요(맵 설정 → 결재자).
- **새 버전을 못 만들어요.** 현재 초안 사이클을 게시까지 끝내세요 — 초안은 한 번에 하나만 존재할 수 있습니다.
- **맵을 실수로 삭제했어요.** 설정 → 삭제 예정에서 7일 이내에 복구하세요.
- **저장이 안 돼요.** 저장 체크리스트를 확인하세요: 시작 노드 1개, 대표 끝 1개, 종료 이름 중복 없음, 일반 노드 다중 출력 없음. (자세한 내용은 **맵 편집** 매뉴얼의 "저장과 검증".)
- **비용을 원·달러 둘 다 못 넣어요.** 회당 비용은 한 통화만 씁니다 — 한쪽을 비운 뒤 다른 통화를 입력하세요.
- **링크한 하위프로세스가 잠겨 있어요.** 그 맵이 아직 서브프로세스로 **지정되지 않은** 상태입니다. 노드 인스펙터의 **Request registration**으로 오너에게 등록을 요청하거나, 내 맵이면 게시 후 맵 설정에서 지정하세요.
- **협업자 권한 변경이 안 돼요.** 대상이 초안을 체크아웃 중이거나 버전 승인을 제출한 상태면, 진행 중인 버전 워크플로가 끝날 때까지 그 사람에 대한 권한 변경이 차단됩니다. 반대로 내 권한 강등이 승인 대기 중이면 체크아웃과 승인 요청이 차단됩니다.
