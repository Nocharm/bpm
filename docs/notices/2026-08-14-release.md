# 업데이트 안내 — 승인 코멘트·협업자 관리·인물/조직 정보 (8월)

이번 업데이트로 아래 기능이 추가·개선되었습니다. 자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 · 사용 안내)에서 확인하실 수 있습니다.

## 승인 워크플로에 코멘트가 생겼습니다

- **단계별 코멘트** — 제출·승인·게시·철회 때 선택 코멘트를 남길 수 있습니다. 반려 사유는 상대방 알림에도 함께 담겨 전달됩니다.
- **코멘트 이력** — 버전 카드·버전 타임라인의 말풍선 버튼으로 그 버전에 오간 코멘트를 한 번에 봅니다.
- 승인/반려 창에는 **요청자의 제출 코멘트**가, 다시 제출할 때는 **직전 반려 사유**가 미리 보여 맥락을 놓치지 않습니다.
- 에디터의 **승인 워크플로 패널이 새로워졌습니다** — 승인 상태 태그에 마우스를 올리면 처리 시각과 코멘트가 툴팁으로 뜨고, 승인자 이름에서는 인물 카드가 열립니다.

## 협업자 관리가 안전하고 편해졌습니다

- **모아서 저장** — 협업자 추가/제거/역할 변경을 쌓아 두고 **Save 한 번**에 적용합니다(Cancel로 전부 취소). 각 변경에는 **즉시 적용되는지, 오너 승인이 필요한지** 아이콘(번개/모래시계)으로 미리 표시됩니다.
- **승인 대기 표시와 회수** — 승인이 필요한 변경은 해당 협업자 행에 대기 태그로 표시되고, 본인이 요청한 건은 그 자리에서 바로 **회수**할 수 있습니다.
- **되돌리기** — 방금 저장한 변경 묶음을 **Undo 한 번**으로 되돌립니다.
- 홈 **맵 카드에서도** 협업자를 바로 추가/제거할 수 있습니다(편집자 이상).
- 오우닝 부서 선택 창이 **조직도 트리**로 바뀌어 내 소속 부서가 맨 위에 고정됩니다.

## 게시와 공개 범위를 한 번에 처리합니다

- 버전 승인을 요청할 때 **공개 범위 변경을 함께 동봉**할 수 있습니다(오너 전용) — 게시되면 같이 적용되고, 반려·철회되면 같이 종결됩니다.
- 공개↔비공개 전환 시 **확인 창에서 승인자를 미리 보여주고**, 승인 대기 중에는 대기 표시와 철회 버튼이 유지됩니다.
- **결재 대기 모아보기** — 설정·에디터 승인 탭에서 공개 범위·권한·이름 변경·서브프로세스 등록 요청을 한 목록으로 처리하고, 좌측 메뉴·받은함에 **대기 건수 배지**가 표시됩니다.

## 사람과 조직 정보가 가까워졌습니다

- 화면 곳곳의 아이디/이름 위에 잠시 머물면 **인물 카드**가 열립니다 — 한/영 이름, 직급·보직, 소속 경로, **메신저 보내기** 링크까지.
- 맵의 허용 인원 목록에서 부서·오우닝 부서 카드를 클릭하면 **조직 정보**(구성 인원·하위 조직)를 바로 확인하고 상위 조직으로 이동할 수 있습니다.
- 버전 히스토리 등의 이름 표기가 **한/영 언어 설정을 따라** 표시됩니다.

## 그 밖에

- **에디터 우측 패널 정리** — 맵 탭 맨 위에서 버전을 고르고, 승인 탭은 결재 대기 → 초안 → 승인 워크플로 순으로 재배치됐습니다. 자주 안 쓰는 섹션은 접혀 있습니다.
- 홈에 **업무체계(Framework) 보기**가 시범 추가되었습니다 — 전사 프로세스 분류 체계로 맵을 탐색하는 보기이며, 현재 준비 단계입니다.
- 인원·조직 정보가 **인사 시스템과 자동 동기화**됩니다 — 조직도와 부서장 표시가 더 정확해지고, 퇴직자는 자동으로 목록에서 빠집니다.
- 관리자 화면의 표(임직원·부서·공지·DB 뷰어)에 **CSV 내보내기**가 생겼습니다.

문의나 불편 사항은 상단 **피드백** 버튼으로 보내주세요.
