이번 업데이트로 아래 기능이 추가·개선되었습니다.
자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 9장 "내보내기", 7장 "저장과 검증", 11장 "업무 체계 연계 캔버스")에서 확인하실 수 있습니다.

## 긴 맵도 Word에서 읽히게: 나눠 싣기

PNG 옵션 창에서 **Word 문서용**을 고르면 오른쪽 인쇄 크기 패널에 **나눠 싣기**가 생겼습니다.

- **읽을 수 있게 나눔**을 고르면 노드 글자가 7pt 이상으로 찍히도록 맵을 **노드 사이 빈 칸에서 세로로 잘라** 조각마다 PNG를 만들고, 전부를 **ZIP 파일 하나**로 내려받습니다.
- 모든 조각이 같은 배율이라 Word에 차례로 넣으면 글자 크기가 일정합니다. 잘린 연결선은 양쪽 조각 끝에 **같은 문자(A·B…)**가 붙고, 조각마다 `1/5` 같은 번호가 들어갑니다.
- **맵 정보 블록과 범례는 인쇄 크기가 고정**됩니다(제목 11pt, 메타·범례 7.5pt). 맵이 길어 그림이 줄어도 같이 작아지지 않습니다.
- **연결선 펼침** 칩으로 같은 핸들의 연결선을 화면처럼 펼칠지(기본) 한 점에서 겹쳐 낼지 고릅니다.
- 표시 정보나 문서 글꼴 때문에 노드 크기가 달라져도 **캔버스에서 맞춘 가운데·오른쪽·아래 정렬이 출력에 그대로** 남습니다.
- 노드의 입력물 상자는 왼쪽 위, 산출물 상자는 오른쪽 아래 모서리가 **사선**으로 잘려 화면과 PNG 모두 모양만으로 구분됩니다.

## 비교 화면 PNG에도 옵션 창이 생겼습니다

비교 화면 **내보내기**를 누르면 **비교 PNG 옵션 창**이 먼저 열립니다.

- **화면 그대로** 또는 **문서용**(흰 바탕, 바뀌지 않은 항목은 회색, 추가·변경·삭제 색은 지금 고른 색 구성 그대로)을 고릅니다.
- **정보 블록**(맵 이름·기준 → 대상 버전·건수), **범례**, 노드에 담을 **표시 정보**를 칩으로 켜고 끄며, 문서용은 인쇄 크기·연결선 펼침·나눠 싣기도 고를 수 있습니다.
- 연결선의 추가·삭제·변경 색과 점선이 이미지에 그대로 담깁니다(전에는 모두 검은 실선이었습니다).

## Excel은 바로 인쇄할 수 있는 문서로 나옵니다

- 맨 위에 맵 이름·주관 부서·오너·버전·게시일·내보낸 시각 정보 줄이 오고, **A4 가로 한 장 폭**에 맞춰 인쇄되며 머리글 행이 쪽마다 반복됩니다. 머리글 행과 이름 열은 고정되고 필터가 걸려 있습니다.
- **소요시간·실작업시간은 Excel 시간 값**(`1.30` → `1:30`)으로 담겨, SUM으로 더해도 시:분이 맞게 합산됩니다.
- 내보내기 창의 미리보기가 실제 파일 모양(정보 줄과 고른 열)을 보여 줍니다.

## CSV 내보내기와 다시 가져오기가 매끄러워졌습니다

- 내보내기 창 안에서 **미리보기와 경고**를 먼저 보고 내려받습니다. 같은 제목의 단계나 이름 없는 단계가 있으면 다시 가져오기 전에 고치도록 알려 줍니다.
- `=`·`+`·`-`·`@`로 시작하는 칸은 Excel이 수식으로 실행하지 않도록 앞에 `'`를 붙여 내보내고, 다시 가져오면 원래 글자로 돌아옵니다.
- 같은 맵으로 다시 가져올 때 제목의 앞뒤 공백은 무시하고 맞추며, 시작 연결은 그대로 둡니다.
- 따옴표가 닫히지 않은 파일은 문제가 시작된 줄을 알려 주고, UTF-8이 아니어서 EUC-KR로 읽은 파일은 글자가 깨지지 않았는지 확인하라고 경고합니다.

## 저장하지 않은 편집을 두고 나가면 확인합니다

- 저장되지 않은 편집이 있을 때 앱 안 다른 화면으로 이동하면 확인창이 뜹니다. **저장하고 이동 / 저장하지 않고 이동 / 머무르기** 중에서 고르세요.
- 브라우저 뒤로 가기는 물어볼 수 없어 바로 저장하고, 탭을 닫거나 새로고침하면 브라우저 경고가 뜹니다.

## 승인 요청 전에 확인하는 것이 늘었습니다

- 종료가 **둘 이상**인 맵은 그중 하나의 **Primary end**를 직접 켜야 승인 요청할 수 있습니다(종료가 하나면 자동). 이 맵을 하위프로세스로 쓰는 부모 맵의 기본 출구가 다른 끝(예: 반려)으로 바뀌지 않게 하기 위해서입니다.
- "갈래는 판단 노드나 병렬 출구로" 규칙을 맵 설정 화면의 승인 요청·셀프 게시도 에디터와 똑같이 확인합니다.
- 제출자가 퇴사했거나 그 맵의 편집 권한을 잃었다면 **시스템 관리자가 대신 게시·회수**할 수 있습니다.
- 진행 중인 버전(Draft·검토 대기·승인됨·거절됨)이 있으면 재게시할 수 없습니다. 버전 이름은 Draft·거절됨 버전에서 check out한 사람·오너·시스템 관리자만 바꿀 수 있고, 만료된 버전은 삭제할 수 없습니다.

## 업무 체계 연계 캔버스(L5)

- **확정 요청**이 대기 중이면 직속 L5 권한자와 시스템 관리자만 check out할 수 있고, 요청한 사람의 화면은 **Confirm requested** 안내와 함께 읽기 전용이 됩니다. 철회하면 곧바로 다시 편집할 수 있습니다.
- 확정이나 확정 요청을 누르면 아직 저장되지 않은 편집을 먼저 저장한 뒤 진행합니다.
- 다른 L5의 L6를 참조하는 노드는 그 맵의 하위프로세스 등록이 해제되면 **지정 해제됨** 배너가 뜨고 끊긴 링크로 셉니다.
- 분류 권한자에서 빠지면 알림으로 알려 드립니다.

## 그 밖의 개선

- 캔버스가 다시 부드러워졌습니다. 가만히 있거나 휠로 이동할 때 끊김이 사라졌고, 맵 전체를 축소한 상태에서 노드를 끄는 것도 빨라졌습니다.
- 내려받는 파일 이름의 시각이 한국 시간으로 붙습니다(오전에 받은 파일이 전날 날짜로 찍히던 문제).
- 볼 권한이 없는 맵은 하위프로세스로 새로 연결할 수 없고, 승인자 목록은 오너와 시스템 관리자만 바꿀 수 있습니다.
- 노드 제목·연결선 라벨·사용자 그룹 이름은 최대 200자입니다.
- 승인 요청 뒤 상단 바에 "편집 중 - 읽기 전용"이 남던 문제와, 좁은 화면에서 저장 버튼이 밀려나던 문제를 고쳤습니다.
- 공지 게시 기간을 수정할 때마다 시작일이 하루씩 당겨지던 문제를 고쳤습니다.
- 사용 매뉴얼 PDF 창은 지금 화면 언어의 PDF를 먼저 보여 줍니다.

## 관리자 화면(시스템 관리자)

- **설정 → 배치 작업**의 HR 카드 아래에 **동기화 회차 이력**이 쌓입니다. 회차마다 신규·퇴직·재입사·삭제·중복 ID 건수가 보이고, 펼치면 바뀐 사람의 명단이 나옵니다. 퇴직 처리가 한꺼번에 많으면 동기화를 멈추지 않고 **Mass departure** 배지로 표시합니다.
- **지금 백업**이 운영 서버에서도 정상 동작합니다.
- 인터뷰 JSON 재전달·AI 컨설턴트 등록에서 사람이 다듬은 값이 같은 활동에 이어집니다(활동을 끼우거나 빼도 값이 옆 활동으로 밀리지 않음). 유지한 L6는 등록이 다시 쓰지 않고, 기존 분류를 다른 상위로 옮기려는 파일은 거부됩니다.
