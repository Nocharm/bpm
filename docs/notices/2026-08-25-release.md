이번 업데이트로 아래 기능이 추가·개선되었습니다. 자세한 사용법은 상단 **사용 매뉴얼**(맵 편집 · 사용 안내)에서 확인하실 수 있습니다.

## 노드에 입출력과 조건을 직접 기록합니다

- 노드마다 **입력물 / 산출물**을 여러 항목으로 등록하고, **시작 / 종료 조건**을 적을 수 있습니다 — 우측 인스펙터의 **입출력 · 조건(I/O & Conditions)** 섹션에서 편집하고, 노드를 선택하면 캔버스의 노드 아래에도 상자로 표시됩니다(표시 항목은 Map 탭 → Node display에서 선택).
- 항목마다 **자료 형식**을 붙일 수 있습니다 — 행의 파일 아이콘을 누르면 자동완성 목록이 열리고, `.xlsx` / `Excel` / `엑셀` 어느 쪽으로 검색해도 같은 항목을 찾아 줍니다.
- **다른 노드의 항목을 그대로 불러올 수 있습니다** — 목록의 **Import from node…** 로 앞 단계의 산출물을 내 입력물로(또는 뒷 단계의 입력물을 내 산출물로) 가져오면, 원본과 **연결(Linked)** 상태가 되어 원본을 고치면 함께 바뀝니다. 연결을 끊고 복사본으로 만들 수도 있습니다.

## 회당 수행 지표가 7개로 늘었습니다

- **실작업시간(Touch time)**이 추가되었습니다 — 소요시간과 같은 `시.분` 규칙(`1.30` = 1시간 30분)입니다. CSV 가져오기/내보내기와 Excel에도 함께 들어갑니다.
- **수행 지표**와 **입출력 · 조건** 편집은 이제 섹션 머리의 **저장(Save)** 버튼으로 반영합니다 — 다 입력한 뒤 한 번에 저장하세요.
- 비용은 **₩/$ 토글이 달린 한 행**으로 정리되었습니다 — 토글로 통화를 바꾸고, 기존 값이 지워지는 경우에는 안내와 되돌리기가 뜹니다.

## 활동별 GMP 분류가 생겼습니다

- 노드를 **GMP Direct / GMP Indirect / Non-GMP**로 분류합니다 — 노드 왼쪽 위 **필 태그**를 클릭해 그 자리에서 고릅니다.
- 분류를 고르면 **노드 색이 분류 색으로 자동 지정**됩니다(Direct=빨강, Indirect=앰버, Non-GMP=초록). 안내 창에서 **이전 분류로 되돌리기 / 색만 되돌리기**를 고를 수 있습니다.
- 하위프로세스 노드는 링크한 맵의 GMP 지정값을 그대로 이어받아 보여줍니다.

## 캔버스가 알아서 자리를 잡습니다

- 입출력 상자 등으로 **노드가 커지면 아래 노드들이 자동으로 밀려나** 겹치지 않습니다 — 화면에서만 조정되고 저장된 좌표는 그대로라, 노드가 작아지면 원위치로 돌아옵니다. 꺾은선 연결선도 커진 노드를 자동으로 우회합니다.
- **빠른 연결** — 연결선을 핸들에 정확히 맞추지 않고 **노드 몸체 위에 놓아도** 바로 연결됩니다. 놓기 전에 연결될 위치가 미리보기로 보입니다.
- 시작·종료 노드의 이름을 바꾸면 **Start / End 타입 필**이 제목과 함께 표시되어 유형을 잃지 않습니다.

## 버전 비교 화면이 새로워졌습니다

- **요약(Summary) 탭** — 두 버전을 숫자로 비교합니다: 7개 수행 지표의 버전 합계(기준 → 대상, 증감), 값을 가진 노드 목록(클릭하면 캔버스 포커스), 구조·시스템·부서/담당자·GMP 분포 섹션.
- **연결선 라벨 변경**도 노랑으로 감지되고, 연결선은 맵에 저장된 **선 모양 그대로** 그려집니다.
- 겹쳐 보이는 노드는 **드래그로 잠시 옮겨** 볼 수 있습니다 — 저장되지 않는 임시 이동이라 버전을 바꾸면 원위치로 돌아옵니다.
- 인스펙터 **Map 탭의 버전 행**에서도 비교를 바로 열 수 있습니다.

## 그 밖에

- **PNG 내보내기**(에디터·비교 화면)에 캔버스 배경과 **맵 정보 카드**(맵 이름·오우닝 부서·오너·버전·게시일)가 함께 담깁니다.
- 업무 체계(Framework)에 등록된 맵은 에디터 캔버스 우상단에 **Framework 칩**이 분류 경로를 보여주고, 같은 분류의 다른 맵으로 바로 이동할 수 있습니다.
- 인스펙터가 정돈되었습니다 — 섹션 아코디언과 **일괄 접기/펼치기** 버튼, 노드 표시 항목의 카테고리 구성(속성 / 수행 지표 / 입출력 · 조건), 그룹 일괄 편집의 카테고리 재편이 함께 적용되었습니다.

문의나 불편 사항은 상단 **피드백** 버튼으로 보내주세요.
