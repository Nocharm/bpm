v1.5.0 안내 이후 바뀐 내용입니다. 일하는 방식이 달라지는 큰 변경은 없고, 지난번에 소개한 **실행 체크**의 이름이 **Run**으로 바뀌고 처음 쓰는 분께 안내가 더 잘 보이도록 다듬었습니다.
자세한 사용법은 상단 **사용 매뉴얼**의 "Run" 장에서 확인하실 수 있습니다.

## 먼저 확인해 주세요

- **한국어 화면에서 "실행"이 "Run"으로 바뀌었습니다.** Draft · Check out처럼 기능 이름을 영어로 고정했습니다. 상단 바 **Run** → **새 Run**, 홈의 **진행 중 Run** 타일, **모든 Run** 창, **Run 범례**처럼 보입니다. 위치와 동작은 그대로이고, 실행취소처럼 Run과 관계없는 "실행"은 바뀌지 않았습니다.

## Run을 처음 쓰는 분께

- **맵에 들어오면 Run 소개가 잠깐 뜹니다.** 아직 Run을 시작해 본 적이 없으면 상단 바 **Run** 버튼 아래에 **새 기능 · Run** 안내가 3초쯤 떴다가 저절로 사라집니다. 마우스를 올린 동안은 멈춥니다. **Run 시작하기**를 누르면 새 Run 창이 열리고, Run을 한 번 시작하면 더는 뜨지 않습니다.
- **Draft에서도 Run 메뉴를 쓸 수 있습니다.** Draft · 결재 중 · 거절 버전에서는 Run 메뉴의 **새 Run** 자리에 **게시본으로 가기**가 나와 Run을 시작할 수 있는 게시본으로 바로 옮겨 갑니다(편집 중이면 버전 전환 확인 창이 먼저 뜹니다). 게시본이 아직 없는 맵만 **Run** 버튼이 꺼지고, 버튼에 마우스를 올리면 이유가 보입니다.
- **새로 만든 빈 맵**에서는 AI 컨설턴트 안내 카드 옆에 Run 소개가 나란히 뜨고, 둘이 함께 닫힙니다.
- **홈에서 첫 Run 권하기**: Run을 써 본 적이 없고 볼 수 있는 게시 맵이 있으면 홈 **진행 중 Run** 타일 아래 줄이 **첫 Run 시작해 보기**로 바뀝니다. 누르면 세 단계 소개 그림(게시본 고르기, 단계 밟기, 문제 · 코멘트 남기기)이 짧게 돈 뒤 Run을 해 볼 맵이 최대 3개(내 맵 먼저) 나오고, 줄의 **새 Run**을 누르면 그 맵의 최신 게시본에서 새 Run 창이 열립니다. 한 번 펼치거나 Run을 한 번 시작하면 그 브라우저에서는 다시 권하지 않습니다.

## 맵 편집

- **서브프로세스 목록은 캔버스 우클릭 후 `S`로 엽니다.** 열린 상태에서 다시 우클릭 후 `S`를 누르면 닫힙니다(메뉴 항목이 **서브프로세스 목록 닫기**로 바뀝니다). 업무 체계 캔버스에서는 L6 업무 목록이 같은 방식입니다. 메뉴 없이 `S`만 눌러 열던 단축키는 없어졌습니다.
- 우클릭 메뉴의 정렬(`A`) 하위 메뉴에서 `S`(세로 자동 정렬)를 누르면 서브프로세스 목록까지 같이 열리던 오류를 고쳤습니다. 다른 우클릭 메뉴의 단축키도 같은 문제가 없도록 함께 고쳤습니다.

## 화면 다듬기

- **제목 글꼴이 바뀌었습니다.** 페이지 제목, 카드와 패널의 제목이 새 제목용 글꼴(Paperlogy)로 보입니다. 본문, 버튼, 표, 캔버스 노드는 그대로입니다.
- **맵을 열면 읽을 수 있는 크기로 시작합니다.** 노드가 많아 전체 맞춤이 너무 작아지는 맵은 시작 노드 쪽을 확대해서 엽니다. 업무 체계 캔버스와 버전 비교는 전처럼 전체를 보여 줍니다.
- **긴 이름과 긴 글이 잘리지 않습니다.** 에디터 아웃라인은 고른 항목을 두 줄로 펴고, 긴 설명은 다섯 줄에서 접어 **더 보기**로 엽니다. 알림 · 공지 카드는 제목을 두 줄까지 보여 줍니다. 띄어쓰기 없는 긴 주소나 식별자도 창 안에서 줄이 바뀝니다.
- **맵 설정 왼쪽 메뉴**가 누른 항목을 정확히 강조합니다.
- **설정 화면의 탭**마다 달랐던 제목과 폭을 맞췄습니다. 모든 탭 위쪽에 제목과 한 줄 설명이 나오고, 내보내기나 새로 만들기 버튼은 그 오른쪽에 있습니다.

## 개발 서버를 쓰시는 분께

- 개발 서버 주소의 포트가 **9910에서 9901로** 바뀌었습니다. 데이터는 그대로입니다. 즐겨찾기를 바꿔 주세요.
