# 노드 IO 연결(불러오기) 설계 — 2026-08-21

노드 인풋/아웃풋의 연결성 강화: 다른 노드의 IO 항목을 "불러오기"로 참조 연결하고, 원본 한 곳에서 수정하면 연결된 모든 항목이 일괄 갱신되는 기능. 브랜치 `feat/io-linking` (base: dev `ecce3d99`).

## 1. 요구사항 요약 (사용자 합의 반영)

1. IO의 + 버튼 → 2항목 메뉴: **Add new**(기존 행 추가) / **Import from node…**(불러오기). + 버튼은 아이콘만, 평소 숨김 — IO 섹션(헤더/목록) 호버 시 표시.
2. 불러오기 선택 모달은 EdgeSelectModal 목록 스타일 + 파일타입 표시. 행 호버 시 해당 노드와 (흐름 경로가 있으면) 엣지 하이라이트.
3. 인풋은 업스트림 노드들의 아웃풋을, 아웃풋은 다운스트림 노드들의 인풋을 후보로 보여줌.
4. 기본 2홉 → "Show more"로 **흐름 내 전체**(엣지 도달 가능 범위)까지 확장. 인풋은 아웃풋만, 아웃풋은 인풋만 가져올 수 있음.
5. 수정은 원본(가장 상류의 아웃풋)에서만. 미러 클릭 시 원본 노드로 네비게이션. 수정하면 모든 미러 일괄 갱신.
6. 인스펙터에서 연결 항목은 링크 아이콘 + 호버 시 상대 노드·엣지 하이라이트.
7. 서브프로세스 IO는 영구 원본·이 맵에서 수정 불가(수정은 링크 맵의 SP 지정에서). SP 항목을 가져온 쪽도 수정 불가.
8. 링크 아이콘 호버 시 Unlink로 스왑, 클릭 → 마우스 근처 확인 팝오버(뷰포트 클램프) → 해제. 해제는 카드 Save 전까지 되돌릴 수 있음.
9. 인풋 항목에 필수/선택 플래그(태그 표시, 기본 필수). 플래그는 **소비 노드 로컬** — 미러여도 그 자리에서 편집, 전파 없음.

## 2. 소유권 모델 — 링크 그룹 불변식

> **한 링크 그룹 = 원본 1개 + 미러 N개.** 원본은 항상 아웃풋(또는 SP 지정 항목). 미러는 읽기전용(텍스트·파일타입), 링크는 평평(flat) — 미러의 미러·순환·원본 2개는 구조적으로 불가능.

불러오기 실행 시점의 동작 (판정은 1회, 이후 엣지 변경에 재판정 없음):

| 케이스 | 동작 |
|---|---|
| 인풋이 아웃풋 항목을 불러오기 | 새 미러 인풋 생성 (원본이 이미 미러면 궁극 원본으로 해소) |
| 아웃풋이 **일반(비연결)** 인풋을 불러오기 | **소유권 인수** — 아웃풋이 원본이 되고 그 인풋은 미러로 전환(텍스트·폼 이관) |
| 아웃풋이 **이미 링크된** 항목을 불러오기, 합류자가 현 원본보다 **상류**(합류자⇝원본 도달 가능, 역방향 불가) | **원본 승계** — itemId를 합류자 아웃풋으로 이동, 구 원본은 미러로 강등. 미러들의 링크 줄은 불변(자동 재지향) |
| 아웃풋이 이미 링크된 항목을 불러오기, 병렬·하류·순환 | **그룹 합류** — 합류자 아웃풋이 미러로 붙음, 편집점 유지 |
| 그룹 원본이 SP 항목 | 항상 미러로 합류 — SP는 영구 원본, 승계 없음 |

- 엣지 삭제는 링크에 영향 없음(링크는 데이터 참조로서 흐름과 독립). 편집점·전파 유지, 하이라이트만 노드 한정. 링크를 끊는 유일한 방법은 명시적 해제.
- 해제 결과: 해제 시점의 텍스트·파일타입을 복사본으로 남기고 링크만 제거(일반 항목 전환).
- 한 항목 = 링크 1개. 인풋이 두 원본을 받으려면 항목을 2개 둔다.

## 3. 데이터 모델

신규 컬럼 6개 — 전부 기존 `*_forms`와 동일한 줄 정렬 텍스트 계약(줄 인덱스 1:1, 빈 줄=없음, 짧으면 이후 없음, trailing rstrip):

| 테이블 | 컬럼 | 내용 |
|---|---|---|
| Node | `output_ids` | 아웃풋 항목 ID — **원본만** 부여(`genId()`, lazy: 누군가 불러가는 순간 부여) |
| Node | `input_links` | 인풋 항목의 원본 참조 — **미러만** 기록 |
| Node | `output_links` | 아웃풋 항목의 원본 참조 (그룹 합류·SP 불러오기) |
| Node | `input_flags` | 인풋 필수/선택 — 빈 줄=required(기본), `optional`만 명시 저장 |
| ProcessMap | `sp_input_ids` | SP 지정 인풋 항목 ID (SP 지정 모달에서 부여) |
| ProcessMap | `sp_output_ids` | SP 지정 아웃풋 항목 ID |

- **`input_ids`는 만들지 않는다** — "원본은 항상 아웃풋(또는 SP)"이 스키마로 강제됨. 항목 상태 판정: `output_ids[i]` 있음=원본 / `*_links[i]` 있음=미러 / 둘 다 없음=일반 / 둘 다 있음=무효(정합화가 링크 소거).
- **링크 참조 형식: 원본 itemId 하나만** (bare). 해석은 렌더 시 맵 전체 인덱스 `{itemId → (노드, out|spin|spout, 줄번호)}` — `output_ids` + SP ref의 `sp_*_ids` 스캔. nodeId를 참조에 넣지 않아 원본 승계=id 이동만으로 끝나고, clone 리매핑도 불필요.
- ID 생성은 `genId()` (`frontend/src/lib/id.ts` — insecure context 제약으로 `crypto.randomUUID` 금지).
- 플래그는 SP IO에 미적용(SP 카드에 태그 미표시).

## 4. UI 플로우

1. **+ 버튼** (`multi-value-input.tsx`): 아이콘만, 섹션 래퍼 `group/iosec` 호버(또는 `focus-visible`) 시 opacity 전환으로 표시. 클릭 → 소형 드롭다운 2항목(Add new / Import from node…). 편집모드 전용.
2. **불러오기 모달** (신규 `io-import-modal.tsx`, EdgeSelectModal 패턴): portal + ModalBackdrop, 버튼 근처 앵커 + 뷰포트 클램프, Esc, 스태거 페이드. 후보는 노드별 그룹핑, 2홉 먼저 → "Show more" 행으로 흐름 내 전체 확장, 상단 텍스트 필터. 행 = `[노드명 필][항목 텍스트][파일타입 필]` + 배지(이미 링크됨=합류 안내, SP=읽기전용 원본). 자기 노드·이미 이 항목에 연결된 대상 제외. 클릭 → §2 규칙 실행, **그래프 상태에 즉시 커밋**(여러 노드를 만지므로 카드 draft 불가).
3. **미러 행** (편집모드): 번호 배지 자리에 Link 아이콘(Lucide 12px), 텍스트 입력·DataFormPicker 비활성, 필수/선택 필은 인풋이면 활성. 아이콘 호버 → Unlink 스왑, 클릭 → 마우스 근처 확인 팝오버(뷰포트 클램프, "복사본으로 남습니다" 안내) → 해제. **해제는 카드 draft 수준** — 인스펙터 IO 카드의 명시 Save(lazy-save) 전 접기/취소로 복귀 가능. × 삭제는 미러에도 유지(그룹 무영향).
4. **네비게이션**: 편집모드에서 미러 텍스트 클릭 → 원본 노드 센터링+선택 → 원본 인스펙터에서 수정.
5. **인스펙터 읽기모드**: 연결 항목(원본·미러 양쪽)에 Link 아이콘. 항목 호버 → 상대편 하이라이트: 미러=원본 노드, 원본=모든 미러 노드, 흐름 경로 있으면 엣지 포함.
6. **하이라이트 상태**: 신규 `ioHighlight {nodeIds, edgeIds}` 하나로 모달 호버·인스펙터 호버 공유. 엣지 집합 = `getFlowPathForward(원본측) ∩ getFlowPathBackward(소비측)` (기존 BFS 재사용, 무제한 홉). `styledEdges` 메모와 노드 하이라이트에 연결.
7. **플래그 태그**: 인풋 행 소형 필(Required/Optional) — 편집모드 클릭 토글, 읽기모드 표시만.

공통: 신규 문자열 en/ko i18n, 인터랙티브 요소 `data-id`(`io-import-*`, `mvrow-link-*` 등), 디자인 토큰만 사용(raw hex 금지), Lucide 16px/1.5(행 내 12px 관례 따름).

## 5. 전파·정합화

전파와 정합화는 결국 같은 일(미러를 원본 값으로 맞추고 무효 링크를 소거)이라 **단일 함수 `propagateIoLinks(nodes, spRefs)`** 로 합쳤다(구 `propagateOriginEdits`/`reconcileIoLinks`). 반환은 `{nodes, changed}` — `changed:false`면 입력 배열을 참조 그대로 돌려줘 불필요한 리렌더가 없다.

**전파** — 원본 텍스트/폼이 저장되는 지점에서 커밋 직전 호출 → 모든 미러 줄 갱신. 배선은 `page.tsx`의 노드 데이터 쓰기 경로 두 곳(`updateSelectedData`=인스펙터 카드 Save, `patchNode`=노드 편집 모달)이며, IO 관련 키가 패치에 있을 때만 돈다(`hasIoPatchField`). 일괄편집 모달(append·replace·clear 전부 지원)은 전파를 트리거하지 않는 대신 정렬로 안전을 보장한다 — `buildBulkAttrPatch`가 기존 텍스트를 줄 경계 접두로 보존하는 변경(동일·append)에서만 줄 1:1 열을 유지하고, 정렬이 깨지는 교체·비우기에서는 그 side의 폼과 링크 열(`input_links`·`input_flags` / `output_ids`·`output_links`)을 **함께 소거**해 링크를 복사본으로 해산시킨다. 남겨두면 잔존 id/link가 새 텍스트의 엉뚱한 행을 가리켜 전파가 맵 전역 미러를 오염시킨다. 원본 항목/노드 삭제 시 해당 미러 전부 자동 해제(복사본 전환). SP 원본은 이 맵에서 수정 불가라 트리거 없음.

**정합화** — 맵 로드 시(루트 스코프 `getGraph` 직후, 그래프의 `subprocess_refs` 동봉) 같은 함수를 1회:
1. itemId 인덱스 구축 (`output_ids` + SP ref `sp_*_ids`)
2. 원본 소실 링크 → 복사본 전환 (CSV/AI id 소거·SP 지정 항목 삭제 등)
3. 원본과 어긋난 미러 텍스트/폼 → 원본 값으로 치유 (SP 지정 변경 등 전파 우회 드리프트)
4. `output_ids`·`*_links` 동일 줄 공존 무효 → 링크 소거; 중복 itemId → 먼저 만난 쪽만 원본, 나머지 소거

변경 발생 시 더티 플래그 → 다음 그래프 PUT에 저장. 읽기전용 진입이면 메모리 치유만.

**한계(명시)**: 미러는 복사본이라, 원본이 다른 경로로 바뀐 뒤 정합화를 거치지 않은 세션에선 구 값이 내보내기에 나갈 수 있음. 편집 세션 내 전파는 즉시.

## 6. 엣지케이스

- 엣지 삭제 → 링크·편집점 유지, 하이라이트는 노드만. (§2)
- 병렬 동시 불러오기 → 그룹 합류, 편집점 유지·전파 일괄. (§2)
- **노드 복사/붙여넣기 → 붙여넣은 노드의 `output_ids` 소거**(itemId 중복 방지), `*_links`는 유지(복사본도 같은 원본의 미러). 기존 노드 복사 경로에 추가.
- 버전 비교 화면 → 미러도 일반 텍스트 표시, 링크 아이콘 미표시 (v1).
- 내보내기(CSV/Excel/Word) → 복사본 텍스트 그대로, 변경 없음. 플래그는 v1 미반영(백로그).
- 권한: 불러오기/해제/플래그 토글 편집모드 전용. 읽기전용은 아이콘·호버만.
- 저장 전 이탈: 불러오기=로컬 그래프 커밋이라 그래프 저장 전 이탈 시 폐기(기존과 동일), 해제=카드 draft라 Save 전 복귀.
