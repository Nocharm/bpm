# 실행 체크(Run) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 게시본 위에서 실제 일 한 건을 노드 단위로 밟아 가는 "실행"(개인·공유)을 만들고, 맵 화면 실행 모드·알림·홈 대시보드·자동 정리까지 잇는다.

**Architecture:** 실행 기록은 맵 그래프와 별도 테이블(`runs` 외 5개)에 저장하고, 노드 상태는 손댄 것만 저장해 나머지는 매번 그래프에서 계산한다. 계산 규칙은 순수 모듈 하나(BE `app/run_graph.py` ↔ FE `lib/run-graph.ts`)가 같은 사례 파일로 맞물리고, 서버가 모든 전이를 다시 판정한다. 맵 화면은 실행 상태를 메인 state에 섞지 않고 `useRunSession` 훅과 `components/run/*`에서 렌더 전용 데이터(`data.runStatus`, `edge.data.runFlow`)로만 얹는다.

**Tech Stack:** FastAPI · SQLAlchemy async · Pydantic v2 · pytest(TestClient) / Next.js · React 19 · @xyflow/react · vitest(jsdom) · Playwright(playwright-core + 시스템 Chrome).

**Spec:** `docs/superpowers/specs/2026-11-04-run-check-design.md` (목업 https://claude.ai/artifact/5ngxKm5G4JJ8go5MesCH3C v9). 계획은 설계를 근거로 하므로 실행자는 둘 다 읽는다. 설계의 **[빌더]** 항목은 이 계획이 아래 "빌더 결정"에서 정했다.

## 빌더 결정 (설계 §5의 [빌더] 항목)

- **루프(역행 연결선)**: 역행 연결선은 기존 판정(FE `findBackEdges(sortedIds, sortLayoutEdges(sortedIds, edges))` ↔ BE `scripts.consultant_layout.find_back_edges`, 노드 id는 오름차순 정렬해 넘긴다)으로 고르고 전파 계산에서 뺀다. 판단 노드에서 역행 갈래를 고르면 "되돌아가기": 그 연결선의 도착 노드에서 판단 노드까지의 고리 안 노드(도착에서 앞으로 닿고, 판단 노드로 앞으로 닿는 노드, 양 끝 포함)의 수동 상태·선택·출구와 그 안 하위프로세스의 하위 범위를 지운다. 알림은 없고 기록(`RunEvent` `loop`)만 남는다.
- **하위프로세스 중첩 상한**: 5단계(에디터 `EXPANSION_LIMITS.maxDepth`와 같음). 범위 경로(`scope_path`)는 에디터 합성 id와 같은 꼴: 루트 `""`, 하위 `"{hostId}"`, 그 아래 `"{hostId}/{subHostId}"`. FE 노드 키 = `scope_path ? \`${scope_path}/${nodeId}\` : nodeId`(`embedId`와 같은 꼴).
- **하위 맵 버전 고정**: 그 범위에서 처음 동작할 때 `subprocess.resolve_linked_version`으로 정하고 `run_scopes`에 저장한다. 맵 화면은 실행 모드에서 고정된 범위의 그래프를 실행 API(`GET /api/runs/{id}/graph?scope=`)로 받아 `buildCompositeTree`의 `getEmbed`에 우선 넣는다.
- **하위프로세스 출구**: 하위 범위가 끝나면(모든 노드 완료·건너뜀) 바깥 노드를 자동 완료하고 출구는 완료된 끝 중 대표 끝(`__primary__`)이 있으면 그것, 없으면 첫 끝의 제목. 바깥 노드의 갈래 종류가 `edge`(레거시 일반 갈라짐)면 자동 완료하지 않고 진행 중으로 둔다(사람이 갈래를 고름). 하위 맵이 끝까지 간 하위프로세스의 완료 취소는 막고 "하위 맵 안에서 먼저 취소" 안내(409)를 준다.
- **하위프로세스 출구 묶음 안의 갈라짐**: 한 출구에 연결선이 여럿이면 병렬로 다룬다(레거시 위반 모양, 설계 §4.2 "최악이라도 한 갈래를 못 체크"보다 덜 막힌다).
- **완료 알림 묶기 창**: 받는 사람에게 같은 실행의 안 읽은 `run_steps_done`이 있으면 그 행을 갱신(개수+1, 행동한 사람 목록, 최근 단계, `created_at` 갱신). 없으면 새 행.
- **공유 실행 동기화**: 실행 화면이 열려 있고 탭이 보이는 동안 10초마다 다시 읽는다(공유 실행만). 내 동작 응답은 전체 상세를 돌려받아 바로 바꾼다. 서버 판정 실패(409)면 최신 상세로 바꾸고 토스트.
- **정리 잡 시각**: 매일 03:30 KST(DB 백업 04:00 전). 실패하면 실패 기록만 남기고 다음 날 다시 돈다.
- **숫자 설정 화면**: 설정 > 콘텐츠 분류(sysadmin)에 새 탭 "Runs".
- **동시성**: 상태를 바꾸는 모든 실행 엔드포인트는 `session.get(Run, run_id, with_for_update=True, populate_existing=True)`로 실행 행을 잠근다(sqlite는 무시, 서버 재판정이 안전망).

규칙(목업 `derive()`·`isLiveEdge()`의 일반화, 설계 §4.2):
- 역행 연결선 판정은 `scripts.consultant_layout.find_back_edges(codes, pairs, labels)`를 함수 안에서 지연 import(`routers/categories.py:876` 선례)해 쓴다. `codes`=노드 id 오름차순, `pairs`=(source, target), `labels`=(source,target)→label. 반환 쌍에 해당하는 연결선 id 전부가 역행이다.
- 위상 순서: 역행을 뺀 연결선으로 Kahn, 같은 차례는 노드 id 오름차순. 남는 노드는 id 오름차순으로 뒤에 붙인다.
- 갈래 종류(`get_branch_options`, 역행 연결선도 선택지에 포함, 순서는 그래프의 연결선 순서):
  - `decision`: 나가는 연결선 ≥2면 `edge`, 아니면 `none`.
  - `subprocess`: 출구 키(`app.subprocess.get_output_key("subprocess", source_handle)`)가 2개 이상이면 `exit`(키는 처음 나온 순서). 1개면 아래 일반 규칙.
  - 그 밖(start 포함): 출구 묶음이 병렬(`start`이거나, 키가 `parallel_outputs`에 있거나, 연결선 ≥2이고 모두 `gateway == "parallel"`)이거나 연결선 ≤1이면 `none`, 아니면 `edge`(레거시 일반 갈라짐 = 택일).
- 살아 있는 연결선: 출발 상태가 `skipped`면 죽음. 출발이 `done`이면 갈래 종류 `edge`는 `choice[출발] == 연결선 id`, `exit`는 연결선 출구 키 `== exit[출발]`일 때만 산다. 그 밖은 산다.
- 상태: `start`=done. 들어오는 정방향 연결선 중 산 것이 없으면 `skipped`. 수동 상태가 있으면 그것. 산 것의 출발이 모두 `done`이면 `end`는 `done`, 나머지는 `ready`. 아니면 `waiting`. `closed`면 `done`·`problem`이 아닌 모든 상태를 `skipped`로.
- 진행률: `ACTIONABLE_TYPES` 노드 중 `skipped` 아닌 수가 분모, `done` 수가 분자. **`closed`를 끈 상태로 계산**(중단 전 기준, 설계 §4.2).
- 끝난 범위: 모든 상태가 `done`/`skipped`.
- 닿은 끝: `done`인 `end` 중 `is_primary_end`가 있으면 `"__primary__"`, 없으면 위상 순서 첫 끝의 `title`, 없으면 None.
- 뒤 단계 손댐: 정방향 연결선으로 닿는 노드 중 `manual`·`choice`·`exit`가 있는 첫 노드(위상 순서)의 제목.
