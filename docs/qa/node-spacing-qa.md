# height-shift 워스트 케이스 브라우저 QA (feat/node-spacing, HEAD f42fd8fb)

M3 겹침 재발 방지를 목적으로, 표시 높이로 커진 노드가 아래 행을 밀어내는 height-shift를 워스트 케이스 맵(긴 라벨·조건 2종·담당 3인·시스템·7파라미터·Input 10줄/Output 6줄)에서 실기동 검수했다.
환경: 격리 sqlite DB + backend 8000(`AI_ENABLED=false DEV_ENFORCE_PERMISSIONS=false`) + frontend 3000 네이티브, 시스템 Chrome(playwright-core, 1800×2200), devUser=admin.sys, 노드 표시 토글 7종 전부 ON. **결과 29/29 PASS.**

시드: `W(0,0)` 워스트 노드 · `N(0,280)` · `P(400,280)`(N과 같은 행) · `Q(0,560)` · `S(800,0)` 하위프로세스(게시+지정된 별도 맵 링크) · `Start(-300,-200)`, 엣지 `W→N`·`N→Q`.
