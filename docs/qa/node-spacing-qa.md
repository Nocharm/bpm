# height-shift 워스트 케이스 브라우저 QA (feat/node-spacing, HEAD f42fd8fb)

# U라운드 — 엣지 장애물 회피 (4c6ce621)

꺾은선(smoothstep) 엣지가 제3 노드의 표시 bbox(팽창 12px)를 관통할 때 빈 회랑으로 우회하는 `lib/edge-detour.ts`를 실기동 검수했다.
환경: 격리 sqlite DB + backend 8000(`AI_ENABLED=false DEV_ENFORCE_PERMISSIONS=false`) + frontend 3000 네이티브, 시스템 Chrome(playwright-core, 1700×1400, zoom 0.75), devUser=admin.sys, 노드 표시 토글 assignee/params/input/output. **결과 13/13 PASS (U1~U6 전항 ✅).**

시드: `A(0,0)` · `W(0,220)`(Input 10줄) · `B(0,760)` · `D(500,0)` · `Start(-700,-400)`, 엣지 `A→B`·`A→D` 둘 다 `line_style=smoothstep`(s-right → t-left).
